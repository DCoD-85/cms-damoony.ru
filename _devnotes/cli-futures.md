# Заметки: Будущее CLI

## 1. Интеграция с Git (Git-driven CLI)
* Автоматический коммит после успешных команд.
* Связь изменений в файлах с сообщениями коммита.
* Проверка состояния репозитория перед выполнением критических команд.
* Git как механизм отката (rollback) при сбоях команд.

## 2. Внешние приложения (External App Integration)
* CLI как API для сторонних программ (Python/C++).
* Использование JSON-режима для бесшовного обмена данными.
* Поддержка протокола IPC (Inter-Process Communication).
* Единый контекст (Domain/Session) между CLI и внешним GUI.
