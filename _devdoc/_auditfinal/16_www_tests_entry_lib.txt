# 16_www_tests_entry_lib

## 1. Назначение

### 36_www_tests_entry
Тест-раннер старого проекта, веб-доступ. tests/index.php — сборка visuo-стека, подключение Stubs, discover через Runner, опционально single suite (?s=), рендер через visuoel tabs. tests/list.php — список suites и архивов. tests/CalculationManager.php — legacy-класс с прямым PDO и SQL-инъекцией, не связан с раннером.

### 37_www_tests_lib
Библиотека тест-раннера старого проекта. Assert — статические проверки с AssertException. CaseResult — результат кейса. Runner — discover/run/stats. Stubs — заглушки main, main_settings, render, VisuoHost для тестов. Suite — набор кейсов с setup. View — visuo-хелперы сводки, кейсов, заголовка вкладки.

## 2. Контракт (Методы)

### 36_www_tests_entry
- index.php: stub error(), stub error_file(), VISUO_SRC, SOURCES, TEST_ROOT, Runner::discover, Runner::run, visuoel->tabs()->page()->data()->set()->add(), visuoel->init(), visuoel->release().
- list.php: файловый скан cases/*.php, require spec, count($spec['tests']); архив — cases archive/*.php (архив не создаётся).
- CalculationManager: process(): bool — $_POST['op'], a, b; PDO('mysql:host=localhost;dbname=test','root',''); switch op; INSERT INTO history.

### 37_www_tests_lib
- Assert: static true, false, null, notNull, eq, same, contains, notContains, instance, count, private fail, private fmt
- AssertException extends Exception
- CaseResult: __construct(string), pass(float), fail(string, float)
- Runner: static discover(string dir): array, run(Suite): array, stats(array): array
- Suite: __construct(string, ?Closure, array), count(): int
- Stubs: классы stub_main_settings, stub_render_data, stub_render, main implements VisuoHost
- View: static summary(array): visuotag, cases(array): visuotag, tab_title(string, array): string

## 4. Edge-cases

### 36_www_tests_entry
- index.php: single suite задан (?s=), не найден — http_response_code(404), exit('Suite not found: ...').
- index.php: single suite найден — обрабатывается только он.
- index.php: log rows_count=0 — visuoel рендерит пустые вкладки.
- list.php: spec не array или нет 'tests' — tests=0.
- list.php: cases пуст — 'Пока нет ни одного suite'.
- list.php: archive пуст — 'Архив пуст'.
- list.php: glob archive_dir — если каталога нет, glob вернёт [].
- CalculationManager::process: op='div' и b==0 — echo 'Error: Division by zero', return false.
- CalculationManager::process: op неизвестен — echo 'Unknown operation', return false.
- CalculationManager: op, a, b подставляются в SQL без экранирования.

### 37_www_tests_lib
- Assert::true: $v !== true — fail('true', var_export).
- Assert::false: $v !== false — fail('false', var_export).
- Assert::null: !== null — fail.
- Assert::notNull: === null — fail.
- Assert::eq: != — fail (loose).
- Assert::same: !== — fail (strict).
- Assert::contains: !str_contains — fail с substr(haystack,0,400).
- Assert::notContains: str_contains — fail.
- Assert::instance: !instanceof — fail с get_class или gettype.
- Assert::count: count !== $expected — fail.
- Assert::fail: throw AssertException с готовым многострочным сообщением.
- Assert::fmt: строка длиннее 200 — substr(0,200).'... (len=N)'.
- Runner::discover: файл не array или нет 'tests' — continue.
- Runner::discover: title отсутствует — basename.
- Runner::discover: setup не Closure — null.
- Runner::discover: ksort по title.
- Runner::run: setup бросил Throwable — все кейсы fail('SETUP FAILED'), return.
- Runner::run: AssertException — fail с сообщением.
- Runner::run: другой Throwable — fail с классом, сообщением, файлом и строкой.
- Runner::run: успех — pass с временем в мс.
- Stubs main::__get — возвращает null для любого несуществующего свойства.
- Stubs main реализует VisuoHost: getRootTag возвращает new visuotag, applyPageOverrides — no-op.
- View::summary: считает passed/failed, ok=failed===0, возвращает root().
- View::cases: для ok — '✓ '+name, для fail — '✗ '+name + pre.case-msg с сообщением.
- View::tab_title: 'name (p/total)'.

## 5. Скрытая логика

### 36_www_tests_entry
index.php определяет VISUO_SRC, SOURCES, TEST_ROOT до визуального стека. Stubs.php подключается дважды (require_once защищает). Runner::discover сортирует ksort по title. Runner::run выполняет setup один раз; при падении setup все кейсы получают fail('SETUP FAILED'). View::summary считает итог по всем suites. visuoel->tabs() создаёт группу вкладок, каждая page()->data()->set() устанавливает заголовок, add() добавляет содержимое. CalculationManager — демонстрационный класс с уязвимостью и не связан с системы тестов; в карте оставлен как есть, но в перенос не входит (в спецификации фиксируется факт наличия).

### 37_www_tests_lib
Assert::fail — единственный источник AssertException, все методы делегируют в fail. Runner::run всегда возвращает CaseResult на каждый ключ tests. CaseResult.time_ms — float мс, для setup fail — 0.0. Stubs::main::__get возвращает null для несуществующих свойств, чтобы старые классы не падали при обращении к main->db, main->library и т.п. в тестах. View::summary возвращает visuotag->root() от локальной vt, а не от родителя. View::cases использует pre для сообщения об ошибке — перенос строк внутри Assert::fail сохраняется.
