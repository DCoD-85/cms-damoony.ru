# 25_visuo_entry_core

## 1. Назначение

### 59_visuo_entry
Загрузчик visuo-стека. visuo/visuo.php подключает источники по фиксированному порядку, при ошибке error_file. VisuoHost — интерфейс для main: getRootTag(): visuotag и applyPageOverrides(visuostruct_html): void.

### 60_visuo_core
Ядро построения дерева и финального рендера. visuotag — билдер дерева тегов с attrs, data, class, style, actions, find, parent, append/prepend, insert, prepare, release, final, releasetree, structv, el, meta, findstruct. visuoattrs и подклассы class/style/actions/data — контейнеры атрибутов с release и attributes_release. visuometa — конструктор meta (title, link), as_tag. visuolink — favicon/css/js с cache-buster. visuolog — лог visuotag. visuorelease — оркестратор final/final_ajax, debug-панель, init html/head/body без схемы. visuorender — чистое преобразование tree + meta в HTML. visuopage — применение override из visuostruct_html к слотам dt_top/left/center/right/bottom. visuorelease_settings — язык из cookie. visuoels — загрузчик visuoel.

## 4. Edge-cases

### 59_visuo_entry
- include_once любого файла false — error_file с путём, файлом, строкой.
- visuo/visuo.php определяет DS/DSA только при отсутствии.
- VisuoHost имплементируется main в engine/main.php и Stubs-классом в tests/lib/Stubs.php.

### 60_visuo_core
- visuotag __construct: visuotag=null — tagname='root', root=true.
- tag: parent — строка -> parent(parent) с eq=0; visuotag -> target=parent; иначе target=this.
- tag: id, class, style устанавливаются через attrs.
- tag: return=false — возвращает target, не newtag.
- structv: tag 'struct' с class cl_struct и visuostruct_name.
- el: tag 'el' с cl_el, visuoel создаётся или передан, init при init=true.
- findstruct: элементы с пустым visuostruct_name — рекурсия; с совпавшим именем — в return и vt.
- parent: root=true -> return $this.
- parent: eq<0 -> return $this.
- parent: пустой tagname — навигация по цепочке без сравнения, eq инкремент.
- find: tagname=null и class=null и id=null — match остаётся false, поиск по классу/тегу идёт вглубь.
- find: tagname задан, class задан — проверяется class->get($class) === $class.
- find: tagname задан, id задан, class null — attrs->get('id') === $id.
- _find: при совпадении — eq сравнение, при eq!== — counter++, продолжение вглубь.
- append: root-пустой — ничего не добавлено.
- append: элементы root_vt — array_merge и rebind_children.
- insert: сначала vt_start->elements в this->elements, затем собственные элементы переносятся в vt_end->elements.
- release: root=true — без обёртки; visuoel подключён — без обёртки.
- release: tag_closed=false — self-closing '<tag />'.
- prepare: visuostruct — prepare_visuostruct (пустая), visuoel — init и добавление vt_start в elements.
- releasetree: подробная debug-строка с attrs, class, style, actions, data, visuostruct; struct-узлы с совпавшим visuostruct_name и visuostruct!=null пропускаются.
- visuolog add: DOCUMENT_ROOT заменяется на '...', счётчик rows_count растёт через ++.
- visuolog add: settings_online=true — print сразу.
- visuolog release: rows пуст — 'Лог пустой'.
- visuolog final: settings_online=false — print release; true — die 'Log is end'.
- visuolog_row as_tag: hrtime сравнивается с предыдущим или $GLOBALS['start_hr'].
- visuometa title/link: добавляют элемент в elements и возвращают его.
- visuometa as_tag: каждый вызов новый visuotag с append всех элементов.
- visuometa_title as_tag: '<title>content</title>'.
- visuolink resolve_rand: явное значение приоритетнее VISUOLINK_RAND_DEFAULT.
- apply_rand: href='' или rand=false — возврат как есть; якорь отделяется, разделитель ? или &; random_int(10000, 99999).
- visuolink as_tag: type не в TYPES или объект не создан — пустой visuotag.
- visuorelease final: struct = main->visuostruct->current(); type json — Content-Type application/json и print as_json; type html — main->applyPageOverrides(struct).
- visuorelease final: иначе debug_attach и print visuorender->html.
- visuorelease final_ajax: html->data_add ajax и ajax-init, затем final.
- debug_attach: body null — return; вычисление ms от $GLOBALS['start'].
- debug_attach: log или debug — сборка debug-блока в div.dt_debug; без них — короткий debugging_onlytime.
- release_min/release_struct — no-op, оставлены для совместимости.
- visuorelease init: doctype + html.cl_html + head.cl_head + body.cl_body.
- visuorender html: head найден — meta встроена; prepare + release + final.
- visuopage apply: main null — return; блок dt_<name> найден — clear и append override или clear при override===false.
- visuorelease_settings __construct: cookie language строка и непустая — язык из cookie.
- visuoels: include_once по стеку — visuotag, attrs, visuoel base, group, group_element, block (element, text, html), message (element, info, success, warning, error), form (fieldset, form), tabs (page), input (element, text, hidden, password, submit, reset, button, email, file, textarea, select, checkbox, radio, checkbox_group, radio_group), field (element, button, block, text, password, email, file, textarea, select, checkbox, radio, checkbox_group, radio_group, submit, reset, button), button (element, submit, reset, button), table (section, row, cell).

## 5. Скрытая логика

### 59_visuo_entry
Порядок загрузки в visuo.php — зависимости должны существовать до подключаемого файла: сначала settings, log, link, tag, attrs, meta, struct, затем visuoel и visuoels, затем render, page, release. visuoels.php сам подключает все visuoel-классы. VisuoHost объявляет контракт, реализация в main возвращает текущий visuotag root через visuorelease.

### 60_visuo_core
visuotag — единое дерево, атрибуты хранятся в visuoattrs, подклассы class/style/actions/data живут в нём же и сериализуются в release в порядке class, style, actions, data, затем остальные атрибуты (attributes_release). Порядок сборки release: сначала children, затем обёртка, root и узлы с visuoel не оборачиваются. prepare() подключает visuoel через vt_start: для visuoel-узла init и добавление vt_start в elements, после этого release даёт содержимое элемента. find — DFS с eq как номер совпадения, counter передаётся по ссылке между поддеревьями. structv создаёт узел 'struct' с cl_struct и хранит visuostruct_name для поиска через findstruct. visuometa::as_tag пересобирает visuotag каждый раз — безопасно для повторного вызова. visuolink::apply_rand корректно обрабатывает уже присутствующий query и якорь. visuolog::add при settings_online=true печатает сразу — используется в debug-режиме. visuorelease::final смотрит main->visuostruct->current() и различает JSON (min/ajax) и HTML; для HTML вызывает main->applyPageOverrides(struct), что через visuopage заменяет слоты dt_top/left/center/right/bottom. visuorender::html чисто вставляет meta в head и возвращает финальный HTML. visuorelease_settings читает язык только из cookie, не из query.
