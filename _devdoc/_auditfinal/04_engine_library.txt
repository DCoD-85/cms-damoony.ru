# 04_engine_library

## 1. Назначение

### 05_engine_library
Набор утилит. library — контейнер сервисов, инстанцирует подмодули через make(). dir — скан директории с рекурсией. file — is_file, чтение и запись файла. gen — генератор случайных id вида id+rand(111111111,999999999). image — ресайз, поворот, сохранение в jpeg/png/gif, конвертация из одного формата в другой. link — построение URL/href с учётом алиасов, GET-параметров, anchor и хоста. url — парсинг текущего URL, статические домен/алиас/base/vars, разбор query, get_return(). vars — валидация типов и значений по правилам, добавление сообщений об ошибке.

### 17_engine_vardump
Отладочный дамп переменных в visuotag. vardump::vardump() рекурсивно обходит массивы и объекты, строит div-иерархию с раскрытием по onclick. vardump::my_vardump() — legacy-версия с HTML-строками и jQuery-обработчиками, возвращает строку.

## 4. Edge-cases

### 05_engine_library
- library.php make: class_exists false — error_class(), throw LogicException.
- library.php __construct: include_once возвращает false для любого подмодуля — error_file().
- library/dir.php get: is_dir false — return $dir_result без изменений.
- library/dir.php get: opendir false — return.
- library/dir.php get: файл '.' или '..' — пропуск.
- library/dir.php get: включение в результат только при (dirs && is_dir) || (files && is_file).
- library/image.php image_resize: source не файл — возврат ['error'=>true, 'message'=>'Source file not found'].
- image_resize: getimagesize false или нет mime — ['error'=>true, 'message'=>'Not an image'].
- image_resize: формат не в jpeg/png/gif — ['error'=>true, 'message'=>'Unsupported format'].
- image_resize: imagecreatefrom* вернул false — ['error'=>true, 'message'=>'Failed to open image'].
- image_resize: imagerotate false — поворот пропускается.
- image_resize: imagecreatetruecolor false — destroy src, return error.
- image_resize: nWidthImportant=true и nWidth>0 — масштаб по nWidth; иначе размеры совпадают с источником.
- image_resize: widthToHeight=true — квадрат по min(w,h).
- image_resize: nType пуст — nType = исходный формат.
- image_resize: тип не gif/jpg/jpeg/jpe/png — bOk=false, ['error'=>true, 'message'=>'Failed to save image'].
- image_resize: alpha=true — прозрачный фон imagecolorallocatealpha(0,0,0,127).
- image_resize: png quality 0-100 пересчитывается в compression 0-9: (100-quality)*9/100.
- library/link.php ahref: base_address is_bool false — DSA.
- ahref: base_address is_bool true — по url() текущего адреса, каждый непустой сегмент через DSA.
- ahref: base_address string — DSA.string.
- ahref: base_address is_array пустой — DSA.
- ahref: user bool false и get непустой — ключ помечен как удаляемый, в финале unset; user true и get непустой — значение из get.
- ahref: use_all_adress_data=1 — все текущие GET попадают в результат; иначе только заданные.
- ahref: в конце '&' обрезается mb_substr.
- ahref: allias_address is_bool true — используется url()->static_domain, склеивается через '.'; лишний '.' обрезается.
- ahref: allias_address is_array пустой — не добавляет домен, host не применяется.
- ahref: host=true — добавляет connect_type (по умолчанию 'https://').
- library/url.php url/urlfull/vars при str=null — использует $_SERVER['REQUEST_SCHEME'].'://'.'SERVER_NAME'.'REQUEST_URI'.
- url: preg_match не нашёл — substr(returnData[5], 1, strlen-1), при пустом пути explode даст [''].
- vars_correct: пустая пара 'a&&b' — пропуск.
- vars_correct: ключ '' — пропуск.
- domain: ':8080' убирается preg_replace('/:\d+$/','').
- domain: revert=true — array_reverse, второй элемент становится host.allias, если второго нет — вторая часть ''.
- get_return: рекурсивный при is_array($v), имя ключа = varname[k] либо k.
- get_return: without содержит путь — add=false, ключ не добавляется.
- library/vars.php check: тип не совпадает с gettype — return null.
- check: string и min<max, len вне диапазона — return var_default.
- check: string и var_ereg не пуст, mb_ereg_match false — return var_default.
- check: string и var_values не пуст, in_array false — return var_default.
- check: integer/double и min<max вне диапазона — return var_default.
- check: var_values == false — приведение к [].
- check: null==true и var_default==false — var_default=NULL.

### 17_engine_vardump
- vardump: class_exists('visuotag') false — error('Отсутствует класс Visuotag').
- vardump: count=0 — создаётся корневой visuotag с div.my_vardump -> div.div_title -> div.div_body.
- vardump: тип object — обход свойств через foreach ($var as $key=>$value).
- vardump: тип array и пустой — цикл foreach не выполняется, вложенный div пуст.
- vardump: остальные типы (string/int/bool/null) — заголовок типа и длины, длина строки через mb_strlen.
- vardump: is_null — title_val=' = NULL', title_len=''.
- vardump: is_bool — title_val ' = true'/' = false', title_len=''.
- my_vardump: varname не пуст или debug — открывает div.my_vardump с заголовком и messagetext.
- my_vardump: count=0 и varname пуст — открывает div class my_vardump.
- my_vardump: else — без обёртки, только строки.
- my_vardump: array пустой — Пустой массив с my_vardump_row.
- my_vardump: object обходится через $var->{$k}.
- my_vardump: пустой object — цикл не выполняется, строк не добавляется.
- my_vardump: скаляр string — htmlspecialchars($v) в span.

## 5. Скрытая логика

### 05_engine_library
library::make() при отсутствии класса бросает LogicException после error_class(), поэтому цепочка прерывается. library_url::init() вызывается из library::__construct() и заполняет static_domain/static_allias/static_base/static_vars из $_SERVER через main->main_path. library_link::ahref() принимает как bool, так и array в allias_address, ветви различаются: true -> статический домен приложения, array -> заданные сегменты алиаса. library_gen::id() добавляет в $this->id[] случайное значение и возвращает его же (побочный эффект — накопительный массив id). library_image::image_resize() возвращает ассоциативный массив, а не бросает исключения. library_vars::error() пишет в main->messages через add('error', ...) с HTML в тексте.

### 17_engine_vardump
vardump() рекурсивный вызов использует общий $visuotag, счётчик count растёт через ++count и уменьшается --count после вложенного вызова. Для объекта в массиве (ветка object внутри array) имя ключа берётся как $k, а значение — $value2=$value (тот же объект). my_vardump() в object-ветке всегда разыменовывает $v = $var->{$k}, что для protected/private свойств даст Warning. HTML в my_vardump содержит inline onclick с jQuery-кодом, склеенным в двойных кавычках, и стили через атрибут style. Легенда заголовка включает actions span с onClick копирования в буфер обмена через navigator.clipboard.writeText.
