# 34_domain_alliasglobal

## 1. Назначение

### 79_domain_alliasglobal_base
База системы alliasglobal (регионы шаблона домена). alliasblock — абстрактный блок: menu, sections, wrapper, enabled/filler_enabled, filler, try_filler(), assemble(), section_add/get/has/remove/names/clear, wrapper_set/clear, show/hide/set_enabled/set_filler_enabled, rebuild(), as_tag(), visuotag(). alliasglobal_filler_trait — публичный трейт с show/hide/is_enabled. alliasglobalscript — база скриптов: __construct вызывает init(), run() вызывается из main::release(). menu.php — меню alliasglobal: new/link/head/text/between/vt, all/get/has/count/names, clear/remove, as_tag/as_link/as_list/as_tag_all. menu_row.php — строка меню с типами link/text/head/between/vt, icon, as_tag(). _template_block.php и _template_script.php — шаблоны для новых блоков и скриптов.

### 80_domain_alliasglobal_regions
Регионы шаблона домена damoony.ru: top, left, center, right, bottom, policy, debug, script/head, script/headers. Каждый регион — alliasblock, default_data() подключает <name>.data.php, где программист настраивает wrapper_set и section_add. Filler-версии <name>_<allias>.php используют alliasglobal_filler_trait и <name>_<allias>.data.php. top — многопанельная навигация (tophead, toppro, toplinks) с menu projects/login/skins/languages/navigate, top.data.php заполняет проекты, логин-панель, скины, языки, навигацию. left — левое меню с fill_* по текущей странице (index/docs/news/downloads/login/registration). bottom — многопанельный футер с 6 панелями (damoony, damoonygame, asptour, links, info, policy). policy — соглашение с короткой ссылкой и попапом через form на visuoel. debug — пустой wrapper. script/head — meta-скрипт: title/css/js. script/headers — язык и skin через cookie и redirect.

## 4. Edge-cases

### 79_domain_alliasglobal_base
- alliasblock::__construct: allias_accepted не строка — allias_accepted=''.
- algoritm: enabled=false — return.
- algoritm: data() вызывает try_filler(); если filler найден — return без default_data.
- try_filler: filler_enabled=false — false.
- try_filler: domain/allias/domain_ns пусты — false.
- try_filler: fillers[domain][allias][name] пуст — false.
- try_filler: файла name_allias.php нет — false.
- try_filler: include_once false или class_exists false — false.
- try_filler: filler создаётся один раз, кэшируется в $this->filler.
- try_filler: method is_enabled на filler есть и вернул false — false.
- try_filler: method data на filler есть — вызывает data() и возвращает true.
- assemble: wrapper_tag непуст — создаёт wrapper, attrs из wrapper_attrs, дети в него; иначе дети в root.
- section_add: перезапись ключа name — section_add заменяет, sections[name]=vt.
- rebuild: menu->clear() (без имени — все меню), wrapper_tag='', wrapper_attrs=[], sections=[], visuotag новый, algoritm() заново. filler не сбрасывается.
- as_tag: enabled=false — пустой visuotag.
- as_tag: dirty — assemble().
- visuotag(): enabled=false — новый пустой visuotag.
- visuotag(): dirty — assemble().
- menu::as_tag: lists[name] не существует или пуст — пустой vt.
- as_tag: разделитель меню добавляется между элементами, кроме между (тип 'between' или 'vt').
- as_tag: separator='' — разделитель не добавляется.
- as_list: внутренний пуст — возвращает пустой inner.
- menu_row::as_tag: type='vt' и vt не null — возвращает vt.
- menu_row::as_tag: type='between' — span.menubetween.
- menu_row::as_tag: type='head' — span.menuhead.
- menu_row::as_tag: type='text' — span.menutext.
- menu_row::as_tag: type='link' — span.menulink (+selected/popup/icon классы), a с href, target=_blank, data-notajax при notajax.
- link с icon и text — attrs title=text, content=''.
- link с comment и popup — span.menucomment с div.menucomment_narrow и div.menucomment_text.
- script::__construct вызывает init(); run() по умолчанию устанавливает run_done=true (базовый).

## 5. Скрытая логика

### 79_domain_alliasglobal_base
alliasblock — ключевая точка сборки регионов: при конструировании создаётся alliasglobal_menu и вызывается init(), который в свою очередь вызывает algoritm(). algoritm делает try_filler(); если filler выключен или не найден — default_data(). После data() всегда assemble(), что гарантирует сборку дерева из sections. try_filler ищет файл по ReflectionClass(getFileName()) — то есть рядом с самим классом блока, и namespace берётся из domain_accepted(false) (например 'damoony'), а не из current namespace. Конфиг fillers читается по main_settings->fillers[domain][allias][name], где domain — domain_real_name, allias — allias_real_name. filler_enabled по умолчанию true, проверяется в try_filler. Dirty-пересборка асинхронна: as_tag/visuotag вызывают assemble() только при dirty=true. section_add перезаписывает одинаковые имена — порядок рендера не важен. rebuild() — принудительная пересборка без сброса filler. menu::as_tag использует separator между элементами; when type='between' и type='vt' — без separator. menu_row::as_tag при иконке с текстом ставит title=text и пустой текст в a — так работает иконочная навигация.

### 80_domain_alliasglobal_regions
Регионы (top/left/center/right/bottom) — alliasblock, их data() подключает <name>.data.php, где программист сам решает, что положить в sections и wrapper. wrapper_set сохраняет wrapper_tag и wrapper_attrs, но в default_data() блоки вызывают wrapper_set до section_add — порядок важен для assemble(). top — самый сложный: в top.data.php сначала идут fill_* (все menu), потом wrapper_set, потом section_add make_tophead/make_toppro/make_toplinks. menu->as_list используется для вывода в панели. left_visuo имеет собственные приватные fill_* и они вызываются из left_visuo.data.php через $this — это единственный регион, где логика вынесена в отдельный файл-класс. bottom строит шесть bottom_nav_panel с внутренними блоками project/link/title. policy использует visuoel-форму с действием на /policy/agreement: после отправки — AJAX или редирект на policy_action (вне списка файлов — UNKNOWN: реализация обработчика policy/agreement не входит в список файлов анализатора). script/headers — единственное место, где ставится cookie lang/language и skin с 307 редиректом: этот скрипт выполняется первым через main::release (перебор alliasglobal->scripts), до head и до рендера. script/head пишет title/css/js в visuorelease->meta через meta->title()->data(), meta->link()->css(), meta->link()->js() — это работает совместно с visuorender::html, где meta встраивается в head перед prepare/final.
