# 23_admin_controllers_security_settings_stub

## 1. Назначение

### 55_admin_controllers_security
Контроллер безопасности. Единая страница с табами policy/users/logs. POST действия: save_policy, reset_devices, create_invite, revoke_invite. Чтение secure/logs/security.log последних 200 строк. Рендер данных Security::get_config, Security::get_data.

### 56_admin_controllers_settings
Контроллер настроек. index — редактирование глобальных параметров logic, connect_type, ui_ajax_forms через SettingsSet, чтение текущих значений из engine.config, списки skin и logic через Scan. db — настройки БД, чтение secure/db.config и вызов DbSave (класс в CS_CMD/DbSave.php отсутствует в списке файлов).

### 57_admin_controllers_stub
Контроллер заглушек. edit — редактирование заглушки домена domains_stub[real] через Config::mutate. list — библиотека заглушек из config/site.stubs.config. save — сохранение всего массива stubs через Config::mutate.

## 2. Контракт (Методы)

## 4. Edge-cases

### 55_admin_controllers_security
- index: tab не в ['policy','users','logs'] — tab='policy'.
- POST save_policy: mode 'blacklist' если явно, иначе 'whitelist'; require_fingerprint по !empty; Security::save_config, AuditLog, redirect policy&saved=1.
- POST reset_devices: login непуст, Security::reset_user_devices(login, self); self из $_SESSION['admin_login']; ok — action_ok, иначе action_ok с пометкой blocked.
- POST create_invite: invite_type 'bind_user' — target_user и role='bind_only'; иначе role из post, whitelist ['admin','super'], иначе 'admin'.
- POST create_invite: Security::create_invite, URL со схемой http/https, host, /admin/?token=...
- POST create_invite: AuditLog с substr(token, 0, 8).
- POST revoke_invite: token непуст — Security::revoke_invite, AuditLog, redirect users&saved=1.
- POST: Throwable любого действия — error_log, продолжение без рендера ошибки пользователю.
- logs: файл есть — @file, реверс, первые 200, json_decode каждой строки; при null — заглушка ts='', ip='', event='?', data=[].
- logs: файл отсутствует — logs=[].
- render security с tab, saved, generated_invite, sec_cfg, admins, logs, meta.

### 56_admin_controllers_settings
- index POST: params собираются только из POST с ключами в allowed [logic, connect_type, ui_ajax_forms].
- index POST: SettingsSet::run(params), AuditLog::action_ok, при ok — redirect settings&saved=1.
- index POST: !ok — render result 'Настройки — ошибка'.
- index GET: engine_cfg и site_cfg инстанцируются всегда — Config бросит RuntimeException, если файлы отсутствуют.
- index GET: skins = Scan::skinsFor(array_key_first(domains_real) ?? 'damoony.ru').
- index GET: logics = Scan::logics(), connectTypes = Scan::connectTypes().
- db GET: db.config отсутствует или json_decode не array — data=[], bases=[], db = дефолт ['localname'=>'visuo_damoony'].
- db POST: require_once CS_CMD/DbSave.php — файла DbSave.php нет в списке репозитория (в карте отсутствует).
- db POST: DbSave::run($_POST), ok — redirect db:settings&saved=1; иначе render result.
- db POST: при Throwable require_once (файл отсутствует) страница падает, без catch.

### 57_admin_controllers_stub
- edit: domain пуст — redirect dashboard.
- edit POST: Config::mutate getKeys(['domains_stub', real], []) -> stub, устанавливаются title и text, setKeys(real, stub), AuditLog, redirect saved=1.
- edit POST: Config::mutate бросил Throwable — не перехватывается, страница падает.
- edit GET: stub = getKeys(['domains_stub', real], []).
- edit GET: saved = !empty($_GET['saved']).
- list: site.stubs.config отсутствует — Config::__construct бросит RuntimeException, страница падает.
- list: stubs null — [].
- save POST: stubs_data = $_POST['stubs'] ?? [], Config::mutate setKeys(['stubs'], stubs_data), redirect stubs:list&saved=1.
- save POST: Throwable — пустой catch, редирект не выполняется.
- save не POST — redirect stubs:list.

## 5. Скрытая логика

### 55_admin_controllers_security
create_invite при bind_user не сбрасывает target_user при отсутствии; при new_user target_user=null. generated_invite устанавливается только в create_invite, при остальных действиях сохраняется пустым, что проверяется в шаблоне (saved && empty(generated_invite)). Все ошибки Throwable гасятся в error_log, пользователь не видит. reset_devices всегда вызывает AuditLog::action_ok, даже если Security::reset_user_devices вернул false — разница только в action-строке. Логи безопасности реверсируются и берутся только последние 200 записей; записи не-array маппятся в заглушку с пустым ts. Страница не проверяет таб отдельно для POST — action различает подтип.

### 56_admin_controllers_settings
SettingsSet пишет в engine.config, а index читает значения из engine.config, поэтому UI показывает актуальные сохранённые значения. Параметр ui_ajax_forms — checkbox, POST может содержать '1' или отсутствовать; SettingsSet валидирует как string (проверка непустоты), '1' проходит. Метод db ссылается на класс DbSave, который не входит в список файлов репозитория — фактическая реализация UNKNOWN: файл CS_CMD/DbSave.php в перечне отсутствует, поведение сохранения не проверено. Redirect при db POST идёт на '?p=db:settings', а не '?p=db' — карта AdminRouter содержит 'db' => SettingsController, action 'settings' должен существовать в SettingsController, но в файле объявлены только index и db — redirect приведёт к 404 dispatch (метод settings отсутствует).

### 57_admin_controllers_stub
edit пишет только title и text в domains_stub[real], но не удаляет другие поля (current, until), которые установлены DomainController::edit. list и save работают с другим файлом — site.stubs.config, отдельным от site.config, где edit пишет domains_stub. save не проверяет CSRF в самом методе — глобальный CSRF в bootstrap ловит POST. Пустой catch в save глушит все ошибки, включая RuntimeException из Config::mutate; пользователь увидит редирект только при успехе.
