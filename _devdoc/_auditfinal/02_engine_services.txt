# 02_engine_services

## 1. Назначение

### 09_engine_log
Накопитель логов в памяти в рамках запроса. log хранит массив log_row, поддерживает добавление, чтение, сброс, рендер в visuotag. log_row — одна запись (message, method, file, line).

### 11_engine_messages
Накопитель пользовательских сообщений в памяти. messages хранит массив записей status, title, text. Допустимые статусы: success, warning, error, console. as_tag() рендерит visuotag по текущему skin. release() возвращает HTML-строку для AJAX.

### 13_engine_mod
Автозагрузчик модулей из engine/mod. mod сканирует директории первого уровня, для каждой ищет файл <name>/<name>.php, инстанцирует класс mod_<name>. init() вызывает init() на каждом модуле.

### 14_engine_render
Обёртка над visuorelease для вывода. render хранит render__data и делегирует установку/получение render_ajax и min. release() вызывает visuorelease->final() или visuorelease->final_ajax() в зависимости от render_ajax.

### 18_engine_visuo
Точка включения библиотеки visuo. Подключает visuo/visuo.php через include_once, при ошибке — error_file().

### 21_engine_cookie
Единая точка установки и удаления cookies с безопасными дефолтами: httponly=true, samesite=Lax, secure=auto по HTTPS, path=/. cookie::set возвращает false при headers_sent. cookie::delete ставит expires на час в прошлое.

## 2. Контракт (Методы)

### 09_engine_log
- log::__construct(main), add(string, string method='', string file='', int line=0): void, all(): array, count(): int, has(): bool, clear(): void, as_tag(): visuotag, astag(): visuotag
- log_row::__construct(log, string, string, string, int), as_tag(): visuotag, astag(): visuotag

### 11_engine_messages
messages::__construct(?main), count(): int, has(): bool, add(string, string, string): void, clear(): void, as_tag(): visuotag, release(): string

### 13_engine_mod
mod::__construct(?main, bool autoload=true), autoload(bool): void, init(): void, get(string): ?object, show_list(): string

### 14_engine_render
- render::__construct(?main, ?render__data), init(): void, data(): render__data, getdata(string): mixed, setdata(string, mixed): void, release(bool log=false, bool debug=false): void
- render__data::__construct(render), init(bool): void, set(string, mixed): void, get(string): mixed

### 18_engine_visuo
Методов нет. Файл-загрузчик верхнего уровня.

### 21_engine_cookie
cookie::set(string name, string value, array opts=[]): bool, cookie::delete(string name, array opts=[]): bool

## 4. Edge-cases

### 09_engine_log
- 09: log::as_tag при пустом rows — возвращает пустой visuotag без элементов.
- 09: log_row::as_tag всегда возвращает visuotag с div.log-row, вложенными div.log-line, div.log-message, div.log-source.
- 09: log_row::as_tag в source конкатенирует method, file и line через пробел и двоеточие.
- 09: astag — алиас as_tag.

### 11_engine_messages
- 11: add: status не в whitelist [success, warning, error, console] — статус принудительно console.
- 11: as_tag: messages пуст — возвращает пустой visuotag без вложений.
- 11: as_tag: main === null — skin=default, пути к иконкам строятся от DSA/media/release/default/.
- 11: release: has() false — возвращает пустую строку.
- 11: release: has() true — возвращает строку visuotag->root()->release().

### 13_engine_mod
- 13: autoload: dir_scan пуст — модули не загружаются.
- 13: autoload: include_once файла вернул false — error_file.
- 13: autoload: класс mod_<name> не определён — new выбросит Error, не перехватывается.
- 13: init: modules пуст — цикл не выполняется, $init остаётся true.
- 13: init: любой модуль вернул false — $init=false, комментарий про $console закомментирован.
- 13: get: модуль не найден — возвращает null.
- 13: show_list: modules пуст — возвращает div Empty modules list.
- 13: show_list: modules не пуст — конкатенирует $return без предварительной инициализации переменной.

### 14_engine_render
- 14: release: main === null — return.
- 14: release: main->visuorelease не установлен — return.
- 14: release: render_ajax=true — final_ajax(log,debug), иначе final(log,debug).
- 14: render__data::set: property_exists false — return, значение не ставится.
- 14: render__data::get: property_exists false — возвращает null.

### 18_engine_visuo
- 18: include_once visuo/visuo.php false — error_file().

### 21_engine_cookie
- 21: set: headers_sent() true — return false, cookie не ставится.
- 21: set: opts['secure']===null — устанавливается true если HTTPS=on, иначе false.
- 21: delete: expires=time()-3600 принудительно, остальные opts передаются в set.

## 5. Скрытая логика

### 09_engine_log
log не пишет в файл, хранит записи только в памяти. log_row::as_tag строит цепочку tag(...)->parent() где parent возвращает на уровень выше. Цепочка заканчивается на div.log-source, поэтому log-message и log-line оказываются вложенными в log-row.

### 11_engine_messages
Пути к иконкам close и full формируются из DSA + media/release/ + skin + icons/min/. Время в сообщении берётся date('H:i d/m/Y', time()) в момент рендера, а не добавления. Класс элемента message_<status> new — двойной класс в атрибуте class. Цепочка visuotag заканчивается на div.button.full -> img src image_full, при этом img создаётся через tag('img', false).

### 13_engine_mod
mod_path задаётся как __DIR__ . DS . 'mod' . DS в объявлении свойства — вычисляется при объявлении класса (константное выражение, __DIR__ допустим). Регистрация модулей: modules[$value] = new $gmod_class($this), где $value — имя директории, $gmod_class = 'mod_'.$value. autoload вызывается из __construct по умолчанию true.

### 14_engine_render
render__data содержит публичные свойства render_ajax (bool, default false) и min (bool, default false, комментарий про использование в visuorelease::final/final_ajax). set/get работают только с уже объявленными свойствами — добавление новых ключей запрещено.

### 18_engine_visuo
Путь вычисляется как dirname(__DIR__).DS.'visuo'.DS.'visuo.php', то есть engine/visuo.php грузит корневой visuo/visuo.php репозитория, не engine/visuo/*.php.

### 21_engine_cookie
DEFAULTS — константный массив класса, merge с opts через array_merge, приоритет opts. secure=null означает auto, а не false. Для SSO через opts можно передать domain.
