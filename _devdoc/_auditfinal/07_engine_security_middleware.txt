# 07_engine_security_middleware

## 1. Назначение

### 12_engine_middleware
Пайплайн обработчиков запроса. middleware хранит стек callable, выполняет по порядку. Статические securityHeaders и rateLimit вызываются из index.php до main::main(). StopMiddleware — исключение для остановки пайплайна.

### 16_engine_user
Аутентификация по cookies. user хранит user_profile. user_profile::init() читает cookies login, password, hash, при непустых login/password делает SELECT из toolsusers, при совпадении заполняет id, login, password, status, data, guest=false; иначе guest=true, data['login']='Гость'.

### 20_engine_blacklist
Проверка IP по blacklist или whitelist. По умолчанию mode=true — чёрный список: при совпадении IP в blacklist.txt deny('Error: badip.'). При mode=false — белый список: при отсутствии IP в whitelist_<domain>_<allias>.txt deny('Error: access denied', 404). Методы allow() и deny() переопределяемы в тестах.

## 2. Контракт (Методы)

### 12_engine_middleware
- StopMiddleware extends Exception
- middleware::add(callable, string=''): self, run(): void, static securityHeaders(bool is_https): void, static rateLimit(string key, int max=60, int window=60, int ban=900): void

### 16_engine_user
- user::__construct(main), is_guest(): bool, authorized(): void
- user_profile::__construct(user), init(): void, set(string, mixed): void, get(string): mixed, data(string): mixed

### 20_engine_blacklist
- blacklist::__construct(?main, ?string data_dir=null), init(): void, check_blacklist(): void, check_whitelist(): void, allow(): void, deny(string message, int http_code=0): void, remote_ip(): ?string, blacklist_file(): string, whitelist_file(): string, load_ips(string file): array

## 3. Зависимости

### 12_engine_middleware
$_SERVER['REMOTE_ADDR'], sys_get_temp_dir(), fopen, flock, json_decode, json_encode, header(), http_response_code().

### 16_engine_user
main, main->db->select(), $_COOKIE['login'], $_COOKIE['password'], $_COOKIE['hash'].

### 20_engine_blacklist
main->main_settings->domain_real_name, allias_real_name, $_SERVER['REMOTE_ADDR'], secure/blacklist/blacklist.txt, secure/blacklist/whitelist*.txt.

## 4. Edge-cases

### 12_engine_middleware
- add: name не задан — генерируется 'm'.count(stack).
- run: стек пуст — ничего не выполняется.
- securityHeaders: всегда ставит X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, Content-Security-Policy.
- securityHeaders: is_https=true — добавляет Strict-Transport-Security.
- rateLimit: fopen($file,'c+') false — return (fail-open, запрос не блокируется).
- rateLimit: flock(LOCK_EX) false — fclose и return (fail-open).
- rateLimit: json_decode не array — data=[], дефолт count=0, start=$now, banned_until=0.
- rateLimit: banned_until>now — http_response_code(429), header Retry-After, throw StopMiddleware.
- rateLimit: (now-start)>window — сброс count=0, start=now.
- rateLimit: count>max — banned_until=now+ban.
- rateLimit: файл блокировок уникален по md5(key.':'.ip).

### 16_engine_user
- user_profile::init: login, password, hash все пусты — return, guest остаётся true.
- init: SELECT вернул пустой row — guest=true, data['login']='Гость'.
- init: SELECT нашёл строку — guest=false, id/login/password/status/data заполнены.
- init: hash читается из cookies, но в SQL не используется.
- set: любое имя свойства ставится без проверки property_exists.
- get: несуществующее свойство — Warning undefined property.
- data: ключ отсутствует — null.

### 20_engine_blacklist
- __construct: data_dir=null — dirname(__DIR__).DS.'secure'.DS.'blacklist'.
- init: mode=true — check_blacklist(); mode=false — check_whitelist().
- check_blacklist: remote_ip null — return.
- check_blacklist: файл не существует — return.
- check_blacklist: IP в списке — deny('Error: badip.').
- check_whitelist: remote_ip null — return.
- check_whitelist: файл не существует — return.
- check_whitelist: IP в списке — allow(); иначе deny('Error: access denied', 404).
- remote_ip: REMOTE_ADDR не строка или пустая — null.
- whitelist_file: allias пуст — имя whitelist.txt; иначе whitelist_<domain>_<allias>.txt.
- load_ips: file_get_contents false — [].
- load_ips: пустая строка после trim — пропуск.
- load_ips: строка начинается с '#' — пропуск (комментарий).
- deny: http_code>0 — http_response_code(code); всегда die(message или 'Error').

## 5. Скрытая логика

### 12_engine_middleware
rateLimit использует файл sys_get_temp_dir()+'/simplcms_rl_'+md5(key.':'.ip), сериализует JSON-объект {count,start,banned_until}. Чтение-запись атомарны под LOCK_EX: stream_get_contents, ftruncate, rewind, fwrite, flock LOCK_UN, fclose. securityHeaders формирует CSP: default-src 'self'; script-src 'self' https://cdn.plyr.io; style-src 'self' 'unsafe-inline' https://cdn.plyr.io; img-src 'self' data:. Комментарий в securityHeaders упоминает, что HSTS, CSRF и auth уже в admin — middleware не дублирует.

### 16_engine_user
SQL-запрос SELECT * FROM toolsusers WHERE login=%s AND password=%s — сравнение с паролем из cookie напрямую, без хэширования на этом уровне. Поле hash из cookies не применяется. user::is_guest() инвертирует profile->get('guest'): если guest=true, возвращает true. user_profile не кэширует результат; повторный init() перечитывает БД.

### 20_engine_blacklist
init() — единственная публичная точка входа, выбирает ветку по $mode. deny() всегда завершает процесс через die(), в тестах переопределяется. allow() — no-op, точка расширения. Загрузка IP в ассоциативный массив $ips[$line]=true, lookup через isset. Один экземпляр blacklist обслуживает либо blacklist, либо whitelist, не оба.
