1. Назначение
Пайплайн обработчиков запроса. middleware хранит стек callable, выполняет по порядку. Статические securityHeaders и rateLimit вызываются из index.php до main::main(). StopMiddleware — исключение для остановки пайплайна.

2. Контракт (Методы)
StopMiddleware extends Exception
middleware::add(callable, string=''): self, run(): void, static securityHeaders(bool is_https): void, static rateLimit(string key, int max=60, int window=60, int ban=900): void

3. Зависимости
$_SERVER['REMOTE_ADDR'], sys_get_temp_dir(), fopen, flock, json_decode, json_encode, header(), http_response_code().

4. Edge-cases
- add: name не задан — генерируется 'm'.count(stack).
- run: стек пуст — ничего не выполняется.
- securityHeaders: всегда ставит X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, Content-Security-Policy.
- securityHeaders: is_https=true — добавляет Strict-Transport-Security.
- rateLimit: fopen($file,'c+') false — return (fail-open, запрос не блокируется).
- rateLimit: flock(LOCK_EX) false — fclose и return (fail-open).
- rateLimit: json_decode не array — data=[], дефолт count=0, start=$now, banned_until=0.
- rateLimit: banned_until>now — http_response_code(429), header Retry-After, throw StopMiddleware.
- rateLimit: (now-start)>window — сброс count=0, start=now.
- rateLimit: count>max — banned_until=now+ban.
- rateLimit: файл блокировок уникален по md5(key.':'.ip).

5. Скрытая логика
rateLimit использует файл sys_get_temp_dir()+'/simplcms_rl_'+md5(key.':'.ip), сериализует JSON-объект {count,start,banned_until}. Чтение-запись атомарны под LOCK_EX: stream_get_contents, ftruncate, rewind, fwrite, flock LOCK_UN, fclose. securityHeaders формирует CSP: default-src 'self'; script-src 'self' https://cdn.plyr.io; style-src 'self' 'unsafe-inline' https://cdn.plyr.io; img-src 'self' data:. Комментарий в securityHeaders упоминает, что HSTS, CSRF и auth уже в admin — middleware не дублирует.
