1. Назначение
Коммутатор подключений модулей движка. include.php — список из 13 модулей в фиксированном порядке. included.php — набор функций для обработки ошибок подключения (bad, include_bad, include_my, include_array) и два define DS, DSA при отсутствии.

2. Контракт (Методы)
include.php — файл верхнего уровня, определяет $sources_dir, $sources_modules, обходит include_once, чистит переменные unset(...). Методов класса нет.
included.php: fo(array, string, string): string; bad(array, string title='Ошибка', string message='Ошибка'): never; include_bad(array, string): never; include_my(array, string): void; include_array(array, array, array=[], string=''): void.

3. Зависимости
DS, DSA, error_file(), visuotag (в комментарии), die().

4. Edge-cases
- include.php: is_file($path) false — error_file() прерывает.
- include.php: include_once false — error_file() прерывает.
- included.php bad: die() всегда, независимо от наличия visuotag; ветка с visuotag закомментирована.
- included.php include_my: include_once false — include_bad() → bad() → die.
- included.php include_array: files пуст — bad('Отсутствуют файлы для подключения').
- included.php include_array: classes не пуст, class_exists false — bad('Отсутствуют классы').

5. Скрытая логика
Порядок в include.php: render, user, blacklist, vardump, log, core, db, library, language, messages, visuo, mod, cookie. Этот порядок определяет последовательность require и влияет на доступность классов при включении. include_array() собирает имена отсутствующих классов в строку через запятую и передаёт в bad().
