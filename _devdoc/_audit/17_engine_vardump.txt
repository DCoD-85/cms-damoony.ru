1. Назначение
Отладочный дамп переменных в visuotag. vardump::vardump() рекурсивно обходит массивы и объекты, строит div-иерархию с раскрытием по onclick. vardump::my_vardump() — legacy-версия с HTML-строками и jQuery-обработчиками, возвращает строку.

2. Контракт (Методы)
vardump::__construct(main), vardump(mixed, ?string varname=null, bool debug=false, bool headers=true, int count=0, ?visuotag=null): visuotag, my_vardump(mixed, string='', bool=false, bool=true, int=0): string

3. Зависимости
main, visuotag, error().

4. Edge-cases
- vardump: class_exists('visuotag') false — error('Отсутствует класс Visuotag').
- vardump: count=0 — создаётся корневой visuotag с div.my_vardump -> div.div_title -> div.div_body.
- vardump: тип object — обход свойств через foreach ($var as $key=>$value).
- vardump: тип array и пустой — цикл foreach не выполняется, вложенный div пуст.
- vardump: остальные типы (string/int/bool/null) — заголовок типа и длины, длина строки через mb_strlen.
- vardump: is_null — title_val=' = NULL', title_len=''.
- vardump: is_bool — title_val ' = true'/' = false', title_len=''.
- my_vardump: varname не пуст или debug — открывает div.my_vardump с заголовком и messagetext.
- my_vardump: count=0 и varname пуст — открывает <div class="my_vardump">.
- my_vardump: else — без обёртки, только строки.
- my_vardump: array пустой — «Пустой массив» с my_vardump_row.
- my_vardump: object обходится через $var->{$k}.
- my_vardump: пустой object — цикл не выполняется, строк не добавляется.
- my_vardump: скаляр string — htmlspecialchars($v) в span.

5. Скрытая логика
vardump() рекурсивный вызов использует общий $visuotag, счётчик count растёт через ++count и уменьшается --count после вложенного вызова. Для объекта в массиве (ветка object внутри array) имя ключа берётся как $k, а значение — $value2=$value (тот же объект). my_vardump() в object-ветке всегда разыменовывает $v = $var->{$k}, что для protected/private свойств даст Warning. HTML в my_vardump содержит inline onclick с jQuery-кодом, склеенным в двойных кавычках, и стили через атрибут style. Легенда заголовка включает actions span с onClick копирования в буфер обмена через navigator.clipboard.writeText.
