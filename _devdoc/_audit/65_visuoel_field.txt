1. Назначение
Группа полей с обёрткой (label + input + hint + error). visuoel_field — прозрачная multi-группа (singleton=false). Элементы: text, password, email, file, textarea, select, checkbox, radio, checkbox_group, radio_group. Каждый тип рендерит собственный div.field.field_<type> с обёрткой box и/или field-label. visuoel_field_block — обёртка над текстом/HTML внутри div.field.field_block с label/content/hint/error. visuoel_field_button/submit/reset extends visuoel_field__button (кнопки с обёрткой поля).

2. Контракт (Методы)
visuoel_field: make_default_data(), build(), text/password/email/file/textarea/select/checkbox/radio/checkbox_group/radio_group(?visuoel__data)
visuoel_field__data extends visuoel_group__data (пустой)
visuoel_field_block: input_type(): 'block', make_default_data() → visuoel_field_block__data, data(), build()
visuoel_field_block__data: text(string): static, html(string): static
visuoel_field_checkbox: input_type(): 'checkbox', make_input(): visuoel_input_checkbox, make_default_data(), data(), build() с полем value
visuoel_field_radio: input_type(): 'radio', make_input(): visuoel_input_radio, make_default_data(), data(), build() с полем value в id
visuoel_field_checkbox_group: input_type(): 'checkbox_group', make_default_data(), data(), build() с options-слотом
visuoel_field_radio_group: input_type(): 'radio_group', make_default_data(), data(), build() с options-слотом
visuoel_field_email/file/password/select/textarea/text: input_type(), make_input(), make_default_data()
visuoel_field_submit/reset/button extends visuoel_field__button: input_type() и make_button()

3. Зависимости
visuoel_group, visuoel_field__element (вне списка), visuoel_field__button, visuoel_input_{text,password,email,file,textarea,select,checkbox,radio,checkbox_group,radio_group}, visuoel_button_{button,submit,reset}, visuotag.

4. Edge-cases
- text/password/email/file/textarea/select/checkbox/radio/checkbox_group/radio_group: передан несовпадающий $__data — создаётся дефолт.
- visuoel_field_checkbox build: name оканчивается на '[]' — id='field_<name>_<value>'; иначе id='field_<name>'.
- visuoel_field_checkbox build: value пуст — value='1'.
- visuoel_field_checkbox build: label пуст — field-name не рисуется.
- visuoel_field_checkbox build: hint непуст и show_hint — рисуется div.hint.
- visuoel_field_checkbox build: error непуст — div.error.
- visuoel_field_radio build: id всегда 'field_<name>_<value>'.
- visuoel_field_checkbox_group build: label непуст и show_label — div.field-label, label_comment опционально.
- visuoel_field_checkbox_group build: vt_end = div.options, туда пришиваются дочерние field_checkbox.
- visuoel_field_radio_group аналогично.
- visuoel_field_block build: label непуст и show_label — label.field-label (htmlspecialchars через esc).
- visuoel_field_block build: content — is_html ? raw : htmlspecialchars.
- visuoel_field_block build: hint/error — esc.
- visuoel_field_block data: text() — is_html=false; html() — is_html=true.
- visuoel_field_button/submit/reset: make_button() возвращает соответствующий visuoel_button__element (вне списка).

5. Скрытая логика
visuoel_field сам не рисует обёртку — каждый дочерний элемент строит свой div.field.field_<type>, что даёт единый стиль через CSS без вложенного контейнера. Для checkbox id учитывает групповое имя (name[]) через суффикс value — это обеспечивает уникальность id для группы. field_block — универсальная обёртка для произвольного текста/HTML внутри field-стиля; используется в таблицах и inline-сообщениях. field_checkbox_group и field_radio_group отличаются от field_checkbox/field_radio тем, что сами не создают input, а дают div.options-слот для дочерних элементов. field_button/submit/reset — переходный слой: обёртка как у field, но рендер кнопки делегируется visuoel_button__element через make_button().
