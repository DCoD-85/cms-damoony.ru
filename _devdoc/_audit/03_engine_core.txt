1. Назначение
Композиция четырёх подмодулей (const, env, path, time) через загрузчик. Точка сборки путей, окружения и таймеров запроса.

3. Зависимости
core_const, core_env, core_path, core_time, error_file(), DS.

4. Edge-cases
- include_once возвращает false — вызывается error_file() с указанием файла и строки.
- core::get возвращает null, если модуль не инициализирован.
- core_env::is_ajax при отсутствии HTTP_X_REQUESTED_WITH возвращает false.
- core_env::is_https проверяет HTTPS=on или X-Forwarded-Proto=https, иначе false.
- core_env::apply в prod отключает E_NOTICE и E_DEPRECATED, display_errors=0.
- core_path::get возвращает пустую строку для неизвестного имени.
- core_time::elapsed_hr_ms использует hrtime(true), делит на 1000000.

5. Скрытая логика
core::is_ajax() делегирует в core_env::is_ajax() повторно (второй независимый вызов в main). core_path::init строит пути относительно __DIR__ подмодуля, sources = dirname(__DIR__), root = dirname(sources), затем www, secure, app.
