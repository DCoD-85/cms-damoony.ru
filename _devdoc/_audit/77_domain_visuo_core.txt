1. Назначение
Утилиты и точка входа visuo. helpers.php: h(), csrf_token/csrf_field/csrf_check, slugify, time_local, now_utc, redirect (по умолчанию 307), json_response, langs_available, lang_default. include.php: определяет константы VISUO_MEDIA_DOWNLOADS и VISUO_MEDIA_IMG, подключает helpers.php и user.php, подменяет $main->user на визуо-пользователя и boot(), подключает algoritm/algoritm.php. routes.php — старый роутер на router\Router с шаблонами URL, не используется движком tree. user.php — визуо-пользователь: extends \user, dp = visuo\dataprovider_user, boot() читает cookie visuo_sid и сессию, authorize, register, logout, update_timezone/update_lang, has_role, can (по PERMISSIONS).

2. Контракт (Методы)
helpers: h, csrf_token, csrf_field, csrf_check, slugify, time_local, now_utc, redirect, json_response, langs_available, lang_default
include.php: верхнеуровневый include, константы, подмена main->user
routes.php: Router::add, return $router
user: __construct(main), boot(), pick_role(array): string, is_guest(): bool, is_auth(): bool, id(): int, login(): string, data(): array, role(): string, tz(): string, lang(): string, has_role(string): bool, can(string): bool, authorize(string, string, bool=false): bool, register(array): array{error,user_id}, logout(), update_timezone(string): bool, update_lang(string): bool, set_cookie/clear_cookie

3. Зависимости
session_start, random_bytes, hash_equals, DateTime, timezone_identifiers_list, filter_var, password_hash/verify, cookie::set/delete, dataprovider_user, dataprovider.

4. Edge-cases
- h: null и '' — ''.
- csrf_token: сессия не активна — @session_start, ключ visuo_csrf.
- csrf_check: метод не POST — true (пропуск).
- csrf_check: пустые token или _csrf — false.
- slugify: пустой результат — 'item-'.substr(md5(...), 0, 8).
- time_local: tz не из timezone_identifiers_list — Europe/Moscow.
- time_local: DateTime бросил Exception — возвращает исходную utc-строку.
- redirect: 307 по умолчанию.
- json_response: Content-Type application/json; charset=utf-8, exit.
- include.php: подмена user только при $this instanceof \damoony_ru\allias и main instanceof \main и текущий user не visuo\user.
- user::boot: booted=true — return.
- boot: dp null, а dataprovider->current не dataprovider — booted=true, return.
- boot: cookie visuo_sid пуст — booted=true, return.
- boot: session_find пуст — clear_cookie, booted=true.
- boot: profile_full пуст — clear_cookie, booted=true.
- boot: успех — current/profile->data/roles/role через pick_role.
- pick_role: admin > editor > reader.
- authorize: dp null — false.
- authorize: check_bruteforce false — false без записи.
- authorize: by_login пуст — record_login_attempt(false), false.
- authorize: password_verify false — record(false), false.
- authorize: status!='active' — record(false), false.
- authorize: успех — session_create с ttl 30d/1d, record(true), touch_login, set_cookie, boot() заново, true.
- register: regex login 3-32 [a-zA-Z0-9_], email filter_var, password>=8, password_confirm==password, !exists(login).
- register: любое нарушение — ['error'=>ERROR_..., 'user_id'=>0].
- register: create id<=0 — error ERROR_500_TEXT.
- register: успех — assign_role(id,'reader'), ['error'=>null,'user_id'=>id].
- logout: dp не null и cookie visuo_sid — session_drop.
- logout: очищает cookie, current=null, profile->data=['login'=>''], roles=[], role=''.
- update_timezone: dp null или guest — false.
- update_timezone: tz не из timezone_identifiers_list — false.
- update_lang: dp null или guest — false.
- update_lang: lang не в [ru-ru, en-en, ch-ch] — false.
- can: role '' — false.
- can: точное совпадение p===action — true.
- can: p оканчивается .* и action начинается с p без .* + '.' — true.

5. Скрытая логика
include.php — единственная точка подмены пользователя в домене damoony.ru: главный user (инженерный) заменяется visuo-пользователем, который работает с visuo_damoony.users и sessions через dataprovider_user. Все страницы algoritm_lang вызывают csrf_check и работают с user->authorize/register/logout — совместимость обеспечивает именно include.php. boot() идемпотентен, но authorize() после успеха ставит booted=false и boot() заново, чтобы загрузить свежие данные после session_create. PERMISSIONS — хардкод в user.php, роли admin/editor/reader. Маршруты routes.php устарели — tree их не использует, реальный роутинг идёт по .rules.json (см. 15_engine_tree). Cookie visuo_sid — единственный признак авторизации, ставится через общий cookie::set.
