1. Назначение
Маршрутизатор админки. Статическая карта resource => Controller, разбор p по ':' на resource и action, подключение BaseController и файла контроллера, инстанцирование, вызов action(). Возвращает bool — false при отсутствии ресурса, файла, класса или метода.

2. Контракт (Методы)
AdminRouter: private static array $map, static dispatch(string $p): bool

3. Зависимости
controllers/BaseController.php, controllers/{Controller}.php.

4. Edge-cases
- dispatch: resource не в карте — false.
- dispatch: BaseController.php отсутствует — require пропускается.
- dispatch: файл контроллера не существует — false.
- dispatch: класс не существует после require — false.
- dispatch: метод не существует на контроллере — false.
- dispatch: action по умолчанию 'index' если ':' не указан.
- dispatch: p='domain:new' — resource=domain, action=new.
- dispatch: p='blocks' — resource=blocks, action=index (в карте BlockController::index отсутствует — false).

5. Скрытая логика
Карта алиасов: dashboard, domain, allias, filler, block/blocks, page/pages, media, settings/db, scheme/schemes, stub/stubs, security, resource/resources. resource 'settings' и 'db' ведут на SettingsController, 'blocks' и 'block' — на BlockController (у BlockController нет метода index), 'pages' и 'page' — на PageController, 'schemes'/'scheme' — на SchemeController, 'stubs'/'stub' — на StubController, 'resource'/'resources' — на ResourceController. Автозагрузка константы CS_* не делает — предполагает bootstrap уже загрузил _lib.
