1. Назначение
Группа вкладок. visuoel_tabs — multi-группа (singleton=false), контейнер div.tabs с div.hhead и div.bbody. visuoel_tabs_page — страница вкладки: span.tab_title с data-tab-target и data-action=tabs-show плюс div.tab_page с id=tab_<spl_object_id>. init() переопределён: сначала build(), затем для каждой страницы page->init(), первая получает class ' selected' на title и page, титулы уходят в vt_head, тела — в vt_body.

2. Контракт (Методы)
visuoel_tabs: $css_class='tabs', $singleton=false, __construct(?visuoel, ?visuoel__data), make_default_data() → visuoel_tabs__data, build(), init(): void, page(?visuoel__data): visuoel_tabs_page
visuoel_tabs__data extends visuoel_group__data (пустой)
visuoel_tabs_page: $css_class='tab_page', data(): visuoel_tabs_page__data, make_default_data() → visuoel_tabs_page__data, build()
visuoel_tabs_page__data: set(string title): static, $title=''

3. Зависимости
visuoel_group, visuoel_group_element, visuoel__data, visuotag, spl_object_id.

4. Edge-cases
- init: повторный вызов — return по флагу $this->init.
- init: элементы не visuoel_tabs_page — пропускаются (continue).
- init: страница без title (vt_title null) — title не добавляется в hhead, класс selected не ставится, но страница всё равно рендерится в bbody.
- page: переданный $__data не visuoel_tabs_page__data — создаётся дефолт.
- build: vt_end = bbody, дети пришиваются в bbody.
- visuoel_tabs_page::build: id = 'tab_' . spl_object_id($this).
- build: title -> data-tab-target=id, data-action=tabs-show; содержимое = esc(title) при непустом.
- build: page -> div.tab_page id=id, vt_end=page (дети внутри страницы).

5. Скрытая логика
init() переопределяет базовый init и вызывает build() до обхода элементов — без этого vt_head/vt_body были бы null. Первая валидная страница помечается selected на двух узлах: tab_title и tab_page — это единственное место, где устанавливается начальный активный таб. Порядок элементов страницы соответствует порядку вызовов page(). data-tab-target работает совместно с JS в старых представлениях: onclick по [data-action=tabs-show] переключает классы selected. spl_object_id стабилен в рамках одного процесса, но разный между запросами — при AJAX-рендере id будет отличаться.
