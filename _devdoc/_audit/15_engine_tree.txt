1. Назначение
Файловый роутер SimplCMS. Заменяет engines/chain/ и engines/router/. Читает .rules.json по сегментам URL, идёт по дереву папок algoritm/, вызывает default() класса, при ошибке рендерит локальную errors/<code>.php, глобальную domain/errors/<code>.php или встроенный HTML.

2. Контракт (Методы)
tree::__construct(main), run(): bool, walk(int level, string class_chain, string path_rel): bool, match(string, array): array, load_and_call(string file, string class_chain): bool, load_rules(string file): ?array, error(int code): bool, log(string msg): void

3. Зависимости
main, main->main_settings->get('logic'), domain_real_name, allias_real_name, domains_namespace, main->library->url->static_base, main->is_guest(), PROJECT_ROOT, TREE_DEBUG.

4. Edge-cases
- __construct: static_base пуст — segments=[]. 
- __construct: trailing пустые удаляются while end===''.
- __construct: ведущие пустые удаляются while reset===''.
- run: walk(0,'algoritm','').
- walk: rules_file не файл — error(404).
- walk: load_rules вернул не array — error(500).
- walk: rules['auth']=true и is_guest — error(403).
- walk: match вернул target=null — error(404).
- walk: target='' — load_and_call текущего файла.
- walk: new_class_file и new_rules_file оба не файлы — error(404).
- walk: new_level >= count(segments) — leaf: leaf_rules не array — error(404); leaf_rules auth и guest — error(403); иначе load_and_call.
- walk: иначе рекурсивный walk на следующий уровень.
- match: pattern не string — continue.
- match: pattern='' и segment='' — ['',null].
- match: pattern содержит '|', regex пуст, segment пуст — [target,null].
- match: regex матчит — [target,target] (args[target]=segment).
- match: pattern === segment — [pattern,null].
- match: иначе [null,null].
- load_and_call: file не файл — error(404).
- load_and_call: class_exists(full_class,false) false — require_once файла; повторная проверка false — error(500).
- load_and_call: new full_class(main,args) бросил \Throwable — error(500).
- load_and_call: default() бросил \Throwable — error(500).
- load_and_call: default() вернул false — error(404).
- load_rules: файл в rules_cache — возврат из кэша.
- load_rules: file_get_contents false или json_decode не array — null.
- error: headers_sent false — http_response_code(code).
- error: local errors/<code>.php найден — include и exit.
- error: global errors/<code>.php найден — include и exit.
- error: fallback — HTML с кодом и текстом 403/404/500/Ошибка, exit.
- log: debug false — return.

5. Скрытая логика
tree не использует autoload домена напрямую: класс собирается как \\namespace\\class_chain, namespace = domain_ns.'\\'.allias, root_class = 'algoritm'. Обход по сегментам URL и по папкам совпадает: new_path_rel наращивается target, new_class_chain = class_chain.'_'.target. match для regex всегда возвращает target как arg_name, то есть имя параметра = имя папки. rules_cache статический, живёт в рамках одного запроса. error() приоритет: локальный путь allias/{alias}/errors/<code>.php, затем domain/errors/<code>.php, затем встроенный HTML с текстом 403 Доступ запрещён, 404 Страница не найдена, 500 Ошибка сервера. log пишет в PROJECT_ROOT/tree.log через file_put_contents с FILE_APPEND при TREE_DEBUG=true.
