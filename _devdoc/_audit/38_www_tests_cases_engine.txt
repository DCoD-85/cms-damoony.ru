1. Назначение
Набор suites старого тест-раннера для движка: blacklist, language, messages, render, tree. Каждый файл возвращает array с title, setup, tests. Тесты используют Assert и заглушки main из lib/Stubs.

2. Контракт (Методы)
Каждый cases/*.php возвращает array{title:string, setup:Closure, tests:array<string, Closure>}.

3. Зависимости
SOURCES/blacklist.php, SOURCES/language.php, SOURCES/messages.php, SOURCES/render.php, SOURCES/tree.php, VISUO_SRC/visuotag.php, visuometa.php, visuolink.php, Assert, main, test_blacklist, fake_visuorelease.

4. Edge-cases
- blacklist setup: создаёт временный каталог damoony2_bl_test в sys_get_temp_dir, очищает файлы, сохраняет в $GLOBALS['bl_tmp'].
- blacklist 'construct': b->main null, mode true.
- blacklist 'blacklist missing file': denied=0.
- blacklist 'blacklist IP matched': denied[0].code=0.
- blacklist 'blacklist comments skipped': '#' в начале — пропуск.
- blacklist 'whitelist base file': allias пуст — whitelist.txt.
- blacklist 'whitelist allias file': whitelist_damoony.ru_login.txt.
- blacklist 'whitelist IP not listed → deny 404': код 404.
- blacklist 'init → blacklist/whitelist': проверка ветвления по mode.
- blacklist 'no REMOTE_ADDR': обе проверки не падают.
- language 'load': язык ru-ru, strings array.
- language 'get existing key': возвращает default при отсутствии ключа.
- language 'get missing → tosave': ключ в strings_tosave.
- language 'get with params': vsprintf.
- language 'savedefaults no crash'.
- language 'set_language chain': возвращает $l.
- messages 'empty state': count=0, has=false, release=''.
- messages 'add 3': count=3.
- messages 'release содержит статусы': message_error/success/warning.
- messages 'unknown status → console': message_console.
- messages 'clear': count=0.
- render 'construct without args': main null.
- render 'set/get min': bool.
- render 'falsy values (regression)': setdata false и getdata false.
- render 'unknown key': getdata null, setdata no-op.
- render 'release no-ajax': final, не final_ajax.
- render 'release ajax': final_ajax.
- render 'release null main' и 'release main without visuorelease': no crash.
- tree 'match: пустой URL → default': target='', arg=null.
- tree 'match: |list для пустого': target='list'.
- tree 'match: regex slug': target='slug', arg='slug'.
- tree 'match: строгое совпадение': 'about'.

5. Скрытая логика
В blacklist тестах используется test_blacklist extends blacklist с переопределением deny/allow — оригинальные методы завершали процесс через die. Тесты tree используют ReflectionMethod на приватный match — прямой вызов для проверки правил без запуска walk. render тест использует fake_visuorelease с полями calls[]. messages release проверяет HTML-содержимое через class иконки message_<status>. language setup не изолирует файлы — реальные inc из проекта language/, тест чувствителен к содержимому.
