назначение
Подраздел описывает консольный интерфейс SimplCMS (corescripts/cli.php) и базовые библиотеки, обеспечивающие разбор аргументов, файловые операции, работу с JSON и построение путей.

контракт (методы)
cli.php
Скрипт верхнего уровня. Проверяет PHP_SAPI === 'cli'. Определяет константы CS_ROOT, CS_LIB, CS_CMD, CS_TPL, PROJECT_ROOT. Подключает библиотеки. Формирует карту команд 
m
a
p
.
Разбирает
map.Разбираетargv. Параметры: --key=value, --flag, позиционные. Вызывает Cli::help при help или неизвестной команде. Подключает файл команды и выполняет ее.

_lib/Cli.php
Класс Cli. Методы: help(array commands): void, out(string): void, err(string): void.

_lib/Fs.php
Класс Fs. Методы: mkdir(path): void, scan_recursive(dir): array, copy_recursive(src, dst): void, remove_recursive(path): void.

_lib/Json.php
Класс Json. Методы: encode(data): string, decode(json, default): mixed, writeAtomic(path, data): void, read(path, default): mixed.

_lib/Paths.php
Класс Paths. Методы: project(): string, logic(): string, logicPath(): string, domain(domain): string, allias(domain, allias): string, algoritm(domain, allias): string, blocks(domain): string, block(domain, block): string, media(domain): string, mediaRoot(): string, mediaShared(): string, skins(domain): string.

зависимости
cli.php зависит от corescripts/_lib/, corescripts/commands/.
Fs.php зависит от RecursiveDirectoryIterator, RecursiveIteratorIterator.
Json.php зависит от Fs::mkdir.
Paths.php зависит от конфигурации проекта (логика, домены), но в просмотренном фрагменте прямые вызовы не видны.

edge-cases
cli.php:4-5 если PHP_SAPI !== 'cli', выполняется die("Only CLI mode allowed\n").
cli.php:29-30 если команда help или отсутствует в $map, вызывается Cli::help и exit(0).
cli.php:32-33 если файл команды не существует, Cli::err и exit(1).
Json.php:10-11 если не удается открыть временный файл для записи, выбрасывается RuntimeException.
Json.php:14-15 если запись неполная, выбрасывается RuntimeException.
Fs.php:5-6 если директория не существует, scan_recursive возвращает пустой массив.
