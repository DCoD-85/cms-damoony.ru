1. Назначение
Центральный класс приложения и реализация VisuoHost. Собирает все сервисы: main_path, main_settings, render, user, blacklist, vardump, log, core, db, library, language, messages, mod, visuopage, visuorelease, visuostruct, visuolog. Управляет последовательностью path → init → logic → savedata → release. main_path — парсинг URL на domain и url. main_settings — загрузка конфигов config/*.json, secure/db.secure, выбор языка, домена, алиаса, skin, title, engine; фильтры доступности домена и алиаса; stubs.

2. Контракт (Методы)
main::__construct(?main_settings), path(?string): void, init(): void, logic(): void, savedata(): void, release(bool log=false, bool debug=false): void, main(?string): void, redirect(?string): void, getRootTag(): visuotag, applyPageOverrides(visuostruct_html): void, is_guest(): bool, is_auth(): bool

4. Edge-cases
- main::path при url=null — берёт из $_SERVER.
- main::init: include.php вернул false — error_file.
- main::init: HTTP_X_REQUESTED_WITH=xmlhttprequest — render->setdata('render_ajax', true).
- main::init: после сборки сервисов вызывает $db->open('login_damoony'), затем user->authorized().
- main::logic: static_domain или static_allias пуст — берёт real и allias_key, выбирает stub_id: maintenance если домен недоступен, maintenance если алиас недоступен. Если stub_id и stubs[stub_id] есть — выводит HTML (html|text|content) с заголовком (title|'Технические работы'), exit.
- main::logic: stub_id не найден — http_response_code(404) и die('Not Found').
- main::logic: new ($static_domain.'\\dataprovider')(main) и new ($static_domain.'\\allias')(main) и т.д. — динамическое имя класса.
- main::logic: alliasscheme->load($static_allias) в try/catch \Throwable — ошибка игнорируется.
- main::logic: alliasscheme->reload() в try/catch \Throwable — ошибка игнорируется.
- main::redirect: печатает '<div>REDIRECT: <b>'.$address.'</b></div>' до переинициализации.
- main_settings::init: loadExternalConfig пропускает отсутствующий файл молча.
- main_settings::init: json_last_error !== JSON_ERROR_NONE или не array — return без изменений.
- main_settings::init: property_exists проверяет имя, иначе поле не обновляется.
- main_settings::init: $base0 в langs_available ['ru-ru','en-en','ch-ch'] — language=$base0; иначе cookie language если в списке.
- main_settings::init: domains_real[$url_allias[0]] не найден — domain_real_name = null, last notice по индексу.
- main_settings::init: alliases_real[domain_real_name][url_allias[1] ?? ''] не найден — allias_real_name = null.
- main_settings::domain_accepted(false): namespace domains_namespace[real] пуст — mb_ereg_replace('\.ru','',real).
- main_settings::domain_accepted: avail=false и until>0 и time()>=until — avail=true.
- main_settings::allias_accepted: avail=false и until>0 и time()>=until — avail=true.
- main_settings::engine: allias null или '' — render_engine['default'] ?? 'algoritm'; иначе render_engine[allias] ?? render_engine['default'] ?? 'algoritm'.
- main_settings::skin('skin'): domains_skins[domain] непусто — оно; иначе $this->skin.
- main_settings::skin('allias') — возвращает skin_allias.
- main_settings::title: domains_titles[domain] непусто — оно; иначе title или 'Site'.
- main_settings::domains(domain_name): domains_real[domain_name] ?: null.
- main_settings::alliases(name) — пустая реализация.
- main_settings::__construct settings по умолчанию render=visuo, language=ru-ru, skin=default; переопределяется $_COOKIE['render'], $_COOKIE['language'], $_COOKIE['skin'].

5. Скрытая логика
main::main вызывает строгую последовательность path → init → logic → savedata → release. main::init подключает autoload первым require_once, затем include.php. Промежуточные сервисы (render, user, blacklist, log, vardump, db, library, language, messages, mod) инстанцируются в фиксированном порядке внутри init, до main_settings->init(). set('connect_type','http://') ставится в init жёстко, хотя main_settings::default() использует https://. domain_accepted(false) используется как namespace-ключ для динамической сборки класса домена: $static_domain = $main_settings->domain_accepted(false), затем new ($static_domain.'\\allias'). tree запускается до reload схемы: сначала tree->run(), потом alliasscheme->reload(). release() перебирает alliasglobal->scripts и вызывает run() на каждом перед render->release(). main_path::set вырезает из URL domain через preg_match группы 4 и url — группа 0 (полный URL). main_settings::loadExternalConfig перезаписывает публичные свойства класса по имени, поэтому sites config/engine.config управляет logic, render_engine, domains_*, alliases_*, fillers, stubs и пр.
