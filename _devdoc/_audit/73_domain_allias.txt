1. Назначение
Доменная точка сборки allias для текущего алиаса. allias::__construct принимает main, читает allias_accepted из main_settings, при непустой строке подключает allias/<name>/include.php. alliasinfo хранит name/subname/history и умеет рендерить их в visuotag. Для damoony.ru это каркас, через который visuo/include.php подменяет $main->user на visuo\user и подключает algoritm.php.

2. Контракт (Методы)
allias: __construct(main), alliasinfo
alliasinfo: __construct(allias), set(string, mixed, bool add_as_array=false), ashtml(), astag(): visuotag

3. Зависимости
main, main->library->link, main->library->url, main->main_settings->allias_accepted(), visuotag, DS, dirname(__DIR__).

4. Edge-cases
- __construct: allias_accepted() null или '' — http_response_code(404), die('Not Found').
- __construct: include_once непустой строки — error_file прерывает.
- alliasinfo::set: add_as_array=true — $this->{$var}[] = $value, иначе перезапись; параллельно history[var][].
- alliasinfo::astag: history непуст — обход двух уровней вложенности, только скалярные значения (массивы не раскрываются).
- alliasinfo::astag: массив в history — печатается '- - - name = Array', значения не выводятся.
- alliasinfo::ashtml — пустая реализация.
- alliasinfo::astag восстанавливает $vt = $vt_old на каждой итерации — итоговый vt не накапливает вложенные фрагменты.

5. Скрытая логика
allias::__construct строит alliasinfo и подключает allias/<allias>/include.php. Через этот include происходит подмена $main->user на visuo\user и загрузка algoritm.php. Имя aлиаса в include_path = allias_accepted() из main_settings, поэтому при выключенном алиасе allias_accepted()=null, и контроллер сразу отдаёт 404. alliasinfo::astag используется для debug и почти повторяет domaininfo::astag (см. 06).
