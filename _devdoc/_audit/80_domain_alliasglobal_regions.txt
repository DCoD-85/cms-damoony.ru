1. Назначение
Регионы шаблона домена damoony.ru: top, left, center, right, bottom, policy, debug, script/head, script/headers. Каждый регион — alliasblock, default_data() подключает <name>.data.php, где программист настраивает wrapper_set и section_add. Filler-версии <name>_<allias>.php используют alliasglobal_filler_trait и <name>_<allias>.data.php. top — многопанельная навигация (tophead, toppro, toplinks) с menu projects/login/skins/languages/navigate, top.data.php заполняет проекты, логин-панель, скины, языки, навигацию. left — левое меню с fill_* по текущей странице (index/docs/news/downloads/login/registration). bottom — многопанельный футер с 6 панелями (damoony, damoonygame, asptour, links, info, policy). policy — соглашение с короткой ссылкой и попапом через form на visuoel. debug — пустой wrapper. script/head — meta-скрипт: title/css/js. script/headers — язык и skin через cookie и redirect.

2. Контракт (Методы)
alliasglobal_top: default_data(), make_tophead/make_toppro/make_toplinks, fill_projects/fill_login/fill_skins/fill_languages/fill_navigate
alliasglobal_left: default_data(), fill_index/fill_docs/fill_news/fill_downloads/fill_login/fill_registration (в filler left_visuo)
alliasglobal_center: default_data()
alliasglobal_right: default_data()
alliasglobal_bottom: default_data(), make_bottomnav()
alliasglobal_policy: default_data(), should_show(): bool, make_shortagreement(), make_agreement(), make_confidence_form(), make_confidence_text()
alliasglobal_debug: default_data()
alliasglobal_script_head: title(string), css(string), js(string), lang(string), run()
alliasglobal_script_headers: init(), handle_language(), handle_skin()
Filler-классы top_<allias>/left_<allias>/center_<allias>/right_<allias>/bottom_<allias>/debug_<allias>: конструктор, data() через data.php, трейт alliasglobal_filler_trait для части filler'ов, флаг enabled по умолчанию true

3. Зависимости
alliasblock, alliasglobal_menu, visuotag, visuoel, visuoel_form/form, visuoel_field/checkbox, visuoel_field_submit/button, main->library->{url,link}, main->language, main->user, main->dataprovider->current, main->visuorelease->meta, cookie::set, $_COOKIE, $_GET, $_SERVER, http_response_code, header, exit, VISUO_MEDIA_DOWNLOADS.

4. Edge-cases
- top.data.php: fill_projects/fill_login/fill_skins/fill_languages/fill_navigate, wrapper_set('div', ['class'=>'top']), section_add tophead/toppro/toplinks.
- top::fill_login: user->is_guest true — ссылки login/registration/help с notajax; иначе — messages/tasks/notifications/friends/profile/logout с иконкой slug.
- top::fill_skins: current из $_COOKIE['skin'] или 'default'; ссылки с href(..., ['skin'=>'default'|'dark']), selected по совпадению.
- top::fill_languages: три ссылки с url_base[0]='ru-ru'/'en-en'/'ch-ch', selected по текущему url_base[0].
- top::fill_navigate: index/docs/news/downloads, selected по url_base[1].
- left_visuo.data.php: current_page = url_base[1], switch по index/docs/news/downloads/login/registration, иначе меню не наполняется.
- left_visuo::fill_index: dp = main->dataprovider->current, если не null — считает sections/articles/news/files, вывод text-строк в menu 'stats', section_add('stats').
- left_visuo::fill_docs: sections пуст — menu->text('docs', DOCS_EMPTY), section_add. Иначе дерево секций и статей с href-построением и подсветкой текущего slug.
- left_visuo::fill_news: две секции — newslist (последние 20) и newsactions (List/Add/Edit/Remove).
- left_visuo::fill_downloads: files из all_active(), иначе DOWNLOADS_EMPTY.
- left_visuo::fill_login: ссылки login/restore.
- left_visuo::fill_registration: ссылки registration/activate.
- left_visuo::human_size — только в downloads на страницах, не в left.
- bottom::make_bottomnav: 3 домена (damoony, damoonygame, asptour) + links + info + policy, каждая в div.bottom_nav_panel.
- bottom::make_bottomnav: ссылки из $link->href с target='_blank', текущий алиас в $url_allias[0].
- bottom::make_bottomnav: info — 3 ссылки Десктоп/Мобильная/Приложение с version=desctop/mobile/app.
- bottom::make_bottomnav: policy — 3 ссылки на /documents/confidence|personal|prilozhenie.
- policy::should_show: cookie policy_agreement != 'accept' — true.
- policy.data.php: короткая ссылка всегда, попап только при should_show().
- policy::make_shortagreement: div.policy_shortagreement с a.href=/privacy (или из lang).
- policy::make_agreement: popup с div.policy_click, div.policy_confidence_close, div.policy_confidence с формой.
- policy::make_confidence_form: form на visuoel с action на [www,<base0>,policy,agreement], три checkbox (form[read], form[get], form[accept]), submit 'Принять', button 'Отказаться'.
- policy::make_confidence_form: обёртка div.policy_confidence_inner с el($ve).
- policy::make_confidence_text: длинный текст соглашения (h1/h2/p).
- debug.data.php: wrapper_set('div', ['class'=>'debug']), секции нет.
- script/head::run: meta null — return; title/css/js добавляются в meta через title()->data(), link()->css/js.
- script/head::run: run_done=true после выполнения, повторно не выполняется.
- script/headers::init: handle_language затем handle_skin.
- script/headers::handle_language: lang priority URL > cookie > default; cookie['lang'] и cookie['language'] ставятся при необходимости; 307 redirect при отсутствии языка в URL.
- script/headers::handle_language: base0 совпадает с кодом языка (mb_ereg '^[a-z]{2}(-[a-z]{2})?$') — замена, иначе array_merge в начало.
- script/headers::handle_skin: ?skin=... — cookie::set('skin', value, expires=0), редирект на URL без skin.
- script/headers::handle_skin: $_GET['skin'] пуст — return.
- filler bottom_<allias>/center_<allias>/left_<allias>/right_<allias>: минимальный data() с test-block и section_add('test', vt).
- filler top_<allias>/top_visuo/top_www: то же, что top_<allias>.
- filler policy_visuo/policy_www: то же через policy->section_add.

5. Скрытая логика
Регионы (top/left/center/right/bottom) — alliasblock, их data() подключает <name>.data.php, где программист сам решает, что положить в sections и wrapper. wrapper_set сохраняет wrapper_tag и wrapper_attrs, но в default_data() блоки вызывают wrapper_set до section_add — порядок важен для assemble(). top — самый сложный: в top.data.php сначала идут fill_* (все menu), потом wrapper_set, потом section_add make_tophead/make_toppro/make_toplinks. menu->as_list используется для вывода в панели. left_visuo имеет собственные приватные fill_* и они вызываются из left_visuo.data.php через $this — это единственный регион, где логика вынесена в отдельный файл-класс. bottom строит шесть bottom_nav_panel с внутренними блоками project/link/title. policy использует visuoel-форму с действием на /policy/agreement: после отправки — AJAX или редирект на policy_action (вне списка файлов — UNKNOWN: реализация обработчика policy/agreement не входит в список файлов анализатора). script/headers — единственное место, где ставится cookie lang/language и skin с 307 редиректом: этот скрипт выполняется первым через main::release (перебор alliasglobal->scripts), до head и до рендера. script/head пишет title/css/js в visuorelease->meta через meta->title()->data(), meta->link()->css(), meta->link()->js() — это работает совместно с visuorender::html, где meta встраивается в head перед prepare/final.
