1. Назначение
Контроллер заглушек. edit — редактирование заглушки домена domains_stub[real] через Config::mutate. list — библиотека заглушек из config/site.stubs.config. save — сохранение всего массива stubs через Config::mutate.

2. Контракт (Методы)
StubController: edit(), list(), save()

3. Зависимости
Config, Paths, PROJECT_ROOT/config/site.stubs.config, AuditLog.

4. Edge-cases
- edit: domain пуст — redirect dashboard.
- edit POST: Config::mutate getKeys(['domains_stub', real], []) → stub, устанавливаются title и text, setKeys(real, stub), AuditLog, redirect saved=1.
- edit POST: Config::mutate бросил Throwable — не перехватывается, страница падает.
- edit GET: stub = getKeys(['domains_stub', real], []).
- edit GET: saved = !empty($_GET['saved']).
- list: site.stubs.config отсутствует — Config::__construct бросит RuntimeException, страница падает.
- list: stubs null — [].
- save POST: stubs_data = $_POST['stubs'] ?? [], Config::mutate setKeys(['stubs'], stubs_data), redirect stubs:list&saved=1.
- save POST: Throwable — пустой catch, редирект не выполняется.
- save не POST — redirect stubs:list.

5. Скрытая логика
edit пишет только title и text в domains_stub[real], но не удаляет другие поля (current, until), которые установлены DomainController::edit. list и save работают с другим файлом — site.stubs.config, отдельным от site.config, где edit пишет domains_stub. save не проверяет CSRF в самом методе — глобальный CSRF в bootstrap ловит POST. Пустой catch в save глушит все ошибки, включая RuntimeException из Config::mutate; пользователь увидит редирект только при успехе.
