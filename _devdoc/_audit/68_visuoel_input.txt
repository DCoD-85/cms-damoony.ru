1. Назначение
Группа полей ввода. visuoel_input — прозрачная группа, обёртка div.input. Методы-фабрики: text, hidden, password, email, file, textarea, select, checkbox, radio, checkbox_group, radio_group, submit, reset, button. Каждый элемент — наследник visuoel_input__element с input_type(). Специализированные элементы: select (переопределяет build — <select><option>), textarea (переопределяет build — <textarea>), checkbox_group/radio_group (рисуют div.options с N input внутри).

2. Контракт (Методы)
visuoel_input: make_default_data(), text/hidden/password/email/file/textarea/select/checkbox/radio/checkbox_group/radio_group/submit/reset/button(?visuoel__data), get_text__data, get_hidden__data, get_password__data, get_email__data, get_file__data, get_textarea__data, get_select__data, get_submit__data
visuoel_input__data extends visuoel_group__data (пустой)
visuoel_input_text/hidden/password/email/file/submit/reset/button/checkbox/radio: input_type(), data(), make_default_data()
visuoel_input_select: input_type(): 'select', build() с select/option
visuoel_input_textarea: input_type(): 'textarea', build() с textarea
visuoel_input_checkbox_group: input_type(): 'checkbox_group', build() с options
visuoel_input_radio_group: input_type(): 'radio_group', build() с options

3. Зависимости
visuoel_group, visuoel_input__element (вне списка), visuotag.

4. Edge-cases
- Каждый метод-фабрика: проверка instanceof $__data, при несовпадении — дефолт.
- get_*_data: перебирает elements, возвращает data() первого совпавшего или null.
- visuoel_input_select build: id/name/autocomplete/size/multiple/required/readonly/disabled добавляются при ненулевых значениях.
- select build: placeholder_option непуст — первый option со value='' и выбранным placeholder.
- select build: options массив value => label, каждая опция — <option value="...">label</option>, selected при совпадении с selected_list.
- select build: selected — массив или одиночное значение (приводится к массиву); сравнение через (string) обеих сторон.
- textarea build: id/name/placeholder/autocomplete/rows/cols/required/readonly/disabled при ненулевых.
- textarea build: value непуст — content с esc.
- checkbox_group build: name пуст или options пуст — пустой div.options.
- checkbox_group build: name не заканчивается на '[]' — добавляется суффикс '[]'.
- checkbox_group build: selected — array или одиночное значение, приводится к массиву строк.
- checkbox_group build: id = 'field_<name без []>_<value>'.
- checkbox_group build: required/disabled добавляются при true.
- radio_group build: selected — array (первый элемент) или одиночное значение.
- radio_group build: name не меняется (без []), id = 'field_<name>_<value>'.
- radio_group build: name пуст или options пуст — пустой div.options.

5. Скрытая логика
visuoel_input — тонкая группа: обёртка div.input, реальная семантика в элементах. select и textarea полностью переопределяют build() — это не <input>, а <select>/<textarea>. checkbox_group и radio_group — единственные, кто рендерит N input в одном build(): они не полагаются на дочерние visuoel_input_checkbox/radio, а сразу генерят HTML по options. Для checkbox_group name приводится к '[]' форме — это стандартный HTML-паттерн для массива значений. get_*_data — legacy-хелперы для доступа к первому data-элементу, замена для старого кода, который мог обращаться к $group->text[0]->data. Все элементы data() приводят к своему __data, но make_default_data может быть переопределён наследником.
