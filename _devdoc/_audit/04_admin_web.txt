назначение
Подраздел описывает точку входа веб-админки SimplCMS: bootstrap.php выполняет инициализацию сессии, заголовков безопасности, автозагрузку библиотек, аутентификацию и маршрутизацию по параметру p.

контракт (методы)
bootstrap.php
Скрипт верхнего уровня. Не содержит классов. Определяет константы CS_ROOT, CS_LIB, CS_CMD, CS_TPL. Подключает библиотеки через require_once. Создает объект Auth. Читает параметр p из $_GET. Выполняет автовход по cookie admin_fp. Проверяет CSRF для POST-запросов логина. Применяет rateLimit для admin:login.

_lib/Auth.php
Класс Auth. Свойства: path, login, hash. Методы: check(): bool, login(login, password): bool, logout(): void, login_name(): string, remote_ip(): string, fails_path(): string, load_fails(): array, save_fails(array): void, is_banned(ip): bool, fails_count(ip): int, record_fail(ip): void, reset_fails(ip): void, delay(usec): void.

edge-cases
bootstrap.php:24-25 если $_SESSION['admin_ok'] пуст, пытается выполнить автовход по cookie admin_fp.
bootstrap.php:32-34 если p === 'login' и метод POST, вызывается rateLimit('admin:login', 10, 60, 1800).
Auth.php:9-10 если IP забанен, login возвращает false с задержкой.
Auth.php:10-11 если hash пуст (admin.config отсутствует или не содержит password_hash), login возвращает false.
Auth.php:11-12 если login или password не совпадают, выполняется record_fail; при количестве неудач >= DELAY_AFTER вызывается delay.
Auth.php:14-15 при успешном входе выполняется session_regenerate_id(true).

скрытая логика
bootstrap.php:25-31 автовход: читает cookie admin_fp, декодирует JSON, вызывает Security::find_device, при совпадении восстанавливает сессию (admin_ok, admin_login, admin_role) и обновляет устройство через Security::touch_device.
Auth.php:11-12 проверка пароля через password_verify, логина через hash_equals.
Auth.php:26-34 файл блокировок хранится в PROJECT_ROOT . FAILS_FILE, данные в JSON, запись через file_put_contents с LOCK_EX.
