1. Назначение
Хранилище строк локализации. Определяет текущий язык из main_settings->get('language'), читает общий файл language/<lang>.inc и доменный language/domains/<domain>/<lang>.inc (доменный перекрывает общий). Пишет недостающие ключи в save.txt.inc при savedefaults().

2. Контракт (Методы)
language::__construct(main), load(): self, set_language(string): self, init(): void, get(string, array params=[], string default=''): string, savedefaults(): void, current(): string, path(string, bool domain=false): string, parser(string): array

3. Зависимости
main, main->main_settings->get('language'), main->main_settings->domain_real_name, DS, dirname(__DIR__).

4. Edge-cases
- __construct: get('language') вернул null — значение ru-ru.
- load(): main_settings->get('language') вернул null — ru-ru.
- path: domain=true и domain_real_name пуст — общий путь (без доменного).
- path: name='save' — save.txt.inc либо domains/<domain>/save.txt.inc.
- parser: path не файл — [].
- parser: file() вернул false — [].
- parser: строка '' — пропуск.
- parser: строка начинается с '#' — пропуск.
- parser: строка начинается с "\t" и $key===null — пропуск, значение не копится.
- get: ключ отсутствует или значение '' — текст = default, ключ добавляется в strings_tosave.
- get: params не пуст — vsprintf, при несоответствии числа параметров поведение vsprintf (Warning, false).
- savedefaults: strings_tosave пуст — return.
- savedefaults: existing содержит ключ — пропуск, added не увеличивается.
- savedefaults: added===0 — return без записи.
- savedefaults: каталог не существует — @mkdir 0755 рекурсивно.

5. Скрытая логика
load() перечитывает language заново, потому что main_settings::init() мог обновить его после конструктора. Общий и доменный файлы сливаются через array_merge, доменный перекрывает общий. savedefaults() пишет только недостающие ключи (strings_tosave минус существующие в existing), сортирует ksort, пишет шапку с датой, каждая строка значения с отступом \t. Формат inc: ключ строкой, значение с табуляцией в начале строки, многострочное значение склеивается через перевод строки, в parser() trim применяется к собранному значению.
