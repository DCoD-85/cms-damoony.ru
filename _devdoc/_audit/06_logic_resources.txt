путь: _devdoc/_audit/06_logic_resources.txt
назначение
Подраздел описывает управление ресурсами (ResourceManager) и низкоуровневый доступ к данным (DataGateway), включая загрузку описаний ресурсов, генерацию SQL для создания и изменения таблиц.

контракт (методы)
corescripts/_lib/ResourceManager.php
Класс ResourceManager. Статическое свойство map (соответствие типов полей SQL-типам). Методы: load(path): array, getSqlType(type): string, generateCreateTableSQL(array resource): string, sync(resources_dir): array.

corescripts/_lib/DataGateway.php
Класс DataGateway. Статическое свойство pdo. Методы: connect(dbLocalName): PDO, query(sql, params, dbLocalName): array, execute(sql, params, dbLocalName): bool, insert(table, data, dbLocalName): int, find(table, id, dbLocalName): ?array, update(table, data, id, dbLocalName): bool.

зависимости
ResourceManager зависит от DataGateway, glob, require файлов *.resource.php.
DataGateway зависит от PDO, параметров подключения к БД (не показаны в просмотренном фрагменте).

edge-cases
ResourceManager.php:6-7 если файл ресурса не найден, выбрасывается RuntimeException.
ResourceManager.php:16-17 если директория ресурсов не существует, sync возвращает пустой массив.
ResourceManager.php:27-28 при ошибке в процессе синхронизации таблицы возвращается массив с ok => false и сообщением об ошибке.
DataGateway.php:18-19 find возвращает null, если запись не найдена.

скрытая логика
ResourceManager.php:9-13 generateCreateTableSQL формирует CREATE TABLE IF NOT EXISTS с полями, используя map для преобразования типов (id -> INT AUTO_INCREMENT PRIMARY KEY, string -> VARCHAR(255), text -> TEXT, boolean -> TINYINT(1) DEFAULT 0, datetime -> DATETIME, integer -> INT, relation -> INT).
ResourceManager.php:14-28 sync перебирает файлы *.resource.php в директории, создает таблицу, проверяет существующие колонки через DESCRIBE, добавляет недостающие через ALTER TABLE ADD COLUMN. Возвращает массив результатов по каждой таблице.
DataGateway.php:3-4 connect создает PDO с ERRMODE_EXCEPTION и FETCH_ASSOC.
DataGateway.php:15-16 комментарий указывает на исправленную ошибку: ранее find возвращал массив массивов, теперь возвращает первую запись или null.

UNKNOWN: файлы *.resource.php в просмотренных директориях репозитория не обнаружены; фактическое содержимое ресурсов не подтверждено.
