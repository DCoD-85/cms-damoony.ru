путь: _devdoc/_audit/01_engine_router.txt
назначение
Подраздел описывает файловый роутер SimplCMS: рекурсивный обход дерева URL на основе правил available в .rules.json и вызов default() целевого класса.

контракт (методы)
tree.php
класс tree. Методы: __construct(main, main_settings), run(): bool, walk(level, class_chain, path_rel): bool, match(segment, available): array, load_and_call(file, class_chain): bool, load_rules(file): ?array, error(code): bool, log(msg): void.

algoritm_.php
базовый класс algoritm_. Методы: __construct(main, args), args(args): void, load_vars(): void, load_data(): void, render_json_node(node): mixed, is_ajax(): bool, is_guest(): bool, is_post(): bool, default(), ajax(), role(), algoritm(), guest(), logged(), ajax_guest(), ajax_logged(), clear(), start(), debug().

algoritmdata_.php
класс algoritmdata_. Методы: __construct(available, auth, search, default), get_available(), get_auth(), get_search(), get_default().

зависимости
tree.php зависит от main->main_settings (domain_real_name, allias_real_name, domains_namespace, get('logic')), main->library->url->static_base, main->is_guest(), PROJECT_ROOT, TREE_DEBUG.
algoritm_.php зависит от algoritmdata_, ReflectionClass, visuoel_*, visuotag, main->render->getdata('render_ajax'), main->is_guest().
algoritmdata_.php самостоятелен, хранит переданные значения.

edge-cases
tree.php:26-27 если файл .rules.json не найден -> error(404).
tree.php:29-30 если в правилах auth не пуст и main->is_guest() -> error(403).
tree.php:34-35 если match вернул target === null -> error(404).
tree.php:47-48 если загруженные leaf_rules не массив -> error(404).
tree.php:49-50 если в leaf_rules auth не пуст и is_guest() -> error(403).
tree.php:75-76 если default() вернул false -> error(404).
algoritm_.php:31-32 default(): если is_ajax() -> ajax(), иначе role().
algoritm_.php:33-34 ajax(): если is_guest() -> ajax_guest(), иначе ajax_logged().
algoritm_.php:35-36 role(): если is_guest() -> guest(), иначе logged().

скрытая логика
tree.php: match() поддерживает шаблоны: пустая строка только для пустого сегмента; строка с | делится на regex и target; regex проверяется через preg_match; прямое совпадение. Ветка |target при пустом сегменте возвращает target. Ветка regex|target сохраняет сегмент в args[target].
tree.php: load_rules кеширует результат в статическом массиве self::$rules_cache.
tree.php: error() ищет локальный шаблон ошибки в allias/{alias}/errors/{code}.php, затем в domain/errors/{code}.php, иначе выводит встроенный HTML и exit.
algoritm_.php: load_vars() подключает файл {ShortName}.vars.php рядом с классом. load_data() читает {ShortName}.data.json и присваивает свойствам значения из ключа default, пропуская null.
algoritm_.php: render_json_node() создает visuoel_<el> если указан el, иначе visuotag с tag/class/id и рекурсивно обрабатывает children.
