1. Назначение
Вся группа algoritm_lang страниц алиаса visuo: index, docs, downloads, download, login, logout, news, profile, registration. Каждый класс extends \algoritm_, в guest/logged вызывает render() или redirect, часть имеет ajax_guest/ajax_logged с логикой visuostruct_min. Роутинг — через .rules.json файлы: available массив паттернов, auth флаг.

algoritm_lang_docs::guest/logged/render_list()

- algoritm_lang: 307 redirect на [base0, 'index'].
- algoritm_lang_docs: sections пуст — message info DOCS_EMPTY, return true.
- algoritm_lang_docs: articles пуст для секции — p.visuo-doc-empty.
- algoritm_lang_docs_page: a пуст — http_response_code(404), message error, back link.
- algoritm_lang_download: default() → false — промежуточный уровень всегда пропускает.
- algoritm_lang_download_page: f пуст или status!='active' — not_found().
- algoritm_lang_download_page: basename filename — защита от traversal.
- algoritm_lang_download_page: realpath(VISUO_MEDIA_DOWNLOADS) или realpath(path) false, или path не начинается с base_dir — not_found().
- algoritm_lang_download_page: increment_downloads до headers.
- algoritm_lang_download_page: headers Content-Type/Disposition/Length/nosniff/no-store, readfile, exit.
- algoritm_lang_downloads: (url_base[2] ?? '') !== '' — default() → false (error route).
- algoritm_lang_downloads: files пуст — message info.
- algoritm_lang_downloads::human_size: B/KB/MB/GB с round.
- algoritm_lang_index: просто строит div.visuo.visuo-index c h1/p/p из lang, section_add('test', vt) в center.
- algoritm_lang_login::ajax_guest: csrf_check false — errors; пустой login/password — ERROR_LOGIN_FAILED; authorize ok — min->form()->set(false, '/ru-ru/profile'), return.
- ajax_guest: authorize fail — ERROR_LOGIN_FAILED.
- ajax_guest: errors — min->error(true), min->messages(vt), min->form(true, null) — reset.
- ajax_guest: без ошибок — render(true) в AJAX.
- render: title из lang, форма с csrf, поля login/password/remember, submit; is_ajax — ajax()->address()->set, ajax()->center()->set(ve->visuotag()); иначе center->visuotag()->el(ve).
- algoritm_lang_logout: guest и ajax_guest — redirect_home; logged/ajax_logged — do_logout с user->logout() и redirect.
- algoritm_lang_news: news пуст — message info.
- algoritm_lang_news_page: n пуст и lang!='ru-ru' — fallback на ru-ru; fallback=true — message warning TRANSLATION_PENDING.
- algoritm_lang_news_page: n пуст после fallback — message error NEWS_NOT_FOUND, back link.
- algoritm_lang_profile: guest возвращает false, logged рендерит профиль. auth=true в правилах.
- algoritm_lang_profile: POST без csrf — молча пропускает; иначе update_timezone/update_lang, ok=true при любом успехе.
- algoritm_lang_profile::row_kv: 30/70 ширина ячеек.
- algoritm_lang_profile::timezone_options: timezone_identifiers_list().
- algoritm_lang_registration::ajax_guest: POST, csrf_check false — errors; user->register(data), error null — ok; иначе errors с lang->get(error).
- ajax_guest: ok — min->messages(success), min->form(false, '/ru-ru/login').
- ajax_guest: errors — min->error(true), min->messages(error vt), min->form(true, null).
- registration render: форма с полями login/email/display_name/password/password_confirm, csrf, submit; is_ajax — ajax()->address()->set, ajax()->center()->set; иначе center->visuotag()->el.
- auth=true в profile.rules.json? по факту в файле auth=false, guest вызывается и возвращает false, что трактуется как 404 tree.
- languages хардкод: ru-ru/en-en/ch-ch.

5. Скрытая логика
Все страницы используют единый паттерн: сначала title через head->title(), затем UI из visuoel или visuotag, затем вставка в center->visuotag() через el() (для visuoel) или section_add() (для vt). AJAX-вариант отличается тем, что вместо center->visuotag() устанавливается visuostruct_ajax->center()->set(ve->visuotag()) и, при необходимости, min-структура для управления формой. Логин/регистрация/логаут работают через visuostruct_min с полями error/messages/form/redirect. download_page — единственное место, где происходит readfile и отдаются headers: Content-Type, Content-Disposition, Content-Length, X-Content-Type-Options, Cache-Control. Защита от traversal: basename + realpath-prefix. download промежуточный уровень возвращает false — фактическая отдача происходит в page/ (slug остаётся в url_base[2]). rules.json: index/login/registration/downloads/news/docs/download — available список сегментов, download/downloads/page используют regex ([a-z0-9-]+)|page. login.rules.json — 'login' в available, но обрабатывается как отдельный класс algoritm_lang_login, что в tree-роутере не задействовано напрямую — страницы вызываются из algoritm.rules.json на уровне 'lang', а сами include_once загружаются через autoload по имени класса (см. 01_engine_autoload).
