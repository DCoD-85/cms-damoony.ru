1. Назначение
Контроллер ресурсов данных админки. index — список *.resource.php в allias/{allias}/resources. sync — вызов ResourceManager::sync. edit — таблица записей по ресурсу, подгрузка relation-справочников. form — форма создания/редактирования записи с типизацией полей, DataGateway insert/update.

2. Контракт (Методы)
ResourceController: index(), sync(), edit(), form()

3. Зависимости
ResourceManager, DataGateway, PROJECT_ROOT/app/alpha.0.0/domain/{domain}/allias/{allias}/resources, $_GET, $_POST, AuditLog.

4. Edge-cases
- index: resources_dir не dir — resources=[].
- index: glob '*.resource.php' пуст — resources=[].
- index: при require файла ресурса res не array — PHP warning, дальше падение на $res['id'].
- index: id в ресурсе = basename без '.resource.php'.
- sync: requirePost; пути ресурсов формируются из get('domain') и get('allias'), не post.
- sync: ResourceManager::sync, synced и errors считаются по results.
- sync: redirect resources с synced и errors в query.
- edit: resource_file не существует — redirect resources.
- edit: require файла ресурса; table = resource['table'].
- edit: rows = SELECT * FROM table ORDER BY id DESC LIMIT 100.
- edit: relation — SELECT id, display AS label FROM field['table'].
- edit: render resource_table с meta.title = resource['title'].
- form: resource_file не существует — redirect resources.
- form: id>0, find null — redirect resource:edit.
- form: relation — SELECT id, display AS label FROM field['table'].
- form POST: пропускаются id и created_at.
- form POST: boolean — !empty → 1 иначе 0.
- form POST: integer/relation — непусто → (int), пусто → null.
- form POST: остальное — (string).
- form POST: id>0 — update, иначе insert; при наличии поля created_at — date('Y-m-d H:i:s').
- form POST: redirect resource:edit.

5. Скрытая логика
Путь ресурсов жёстко содержит alpha.0.0 и не использует Paths::logic(). sync берёт domain/allias из GET, хотя форма в resources_list отправляет POST — редирект после sync работает, но параметры в URL формируются из GET. form отправляет POST на тот же URL, но action пустой — форма отправляется по текущему URL. Тип relation в insert сохраняет null при пустом значении, а не 0. created_at ставится только при insert и только если поле объявлено в ресурсе. DataGateway::connect кэширует PDO, поэтому несколько ресурсов в одном запросе используют одно соединение и один localname (первый подходящий), не свой per-resource.
