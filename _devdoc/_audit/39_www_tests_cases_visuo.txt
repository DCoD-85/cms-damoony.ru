1. Назначение
Suites старого тест-раннера для visuo: visuoattrs и подклассы (class, style, actions, data), visuoel-базовые и группы (button, form, form_fieldset, input, table), visuolink, visuolog, visuometa, visuorelease (включая visuorelease_settings), visuostruct (html/min/ajax), visuotag.

2. Контракт (Методы)
Каждый cases/*.php возвращает array{title:string, setup:Closure, tests:array<string, Closure>}. Тесты вызывают Assert::*, создают visuotag/visuoel/visuoattrs и проверяют release().

3. Зависимости
visuo/sources/visuoattrs.php и подпапки, visuo/sources/visuotag.php, visuolink.php, visuometa.php, visuolog.php, visuorender.php, visuorelease_settings.php, visuopage.php, visuostruct.php, visuorelease.php, visuoels.php, Assert, main.

4. Edge-cases
- visuoattrs 'empty': release='' и visuotag возвращается тем же объектом.
- visuoattrs 'add_empty flag': add без третьего аргумента — has=false; add('data-y','',true) — has=true.
- visuoattrs 'falsy value regression': '0' сохраняется как '0', не null.
- visuoattrs 'class_remove': класс удаляется из массива.
- visuoattrs 'style': 'color:red; font-size:14px' → 'color:red;font-size:14px;'.
- visuoattrs 'release order': class < style < actions < id.
- visuoattrs 'escaping generic': xss-значение экранируется.
- visuoattrs 'data через attrs': data-role="admin", data-info=...
- visuoattrs 'data cleared by clear()': data-role пропадает.
- visuoattrsactions 'non-event rejected': href отбрасывается whitelist'ом событий.
- visuoattrsactions 'empty value rejected': пустое значение не добавляется.
- visuoattrsactions 'case insensitivity': ONCLICK → onclick.
- visuoattrsactions 'release full=false trims': без ведущего пробела.
- visuoattrsactions 'escaping': <script> экранируется.
- visuoattrsclass 'add many': разбивка 'dark rounded' в 2 элемента.
- visuoattrsclass 'dedup': 'a','b','a' → 2.
- visuoattrsclass 'remove': 'dark rounded' удаляет оба.
- visuoattrsclass 'whitespace trim': лишние пробелы режутся.
- visuoattrsdata 'null value json': data-x="null".
- visuoattrsdata 'false zero json': data-a="false", data-b="0".
- visuoattrsdata 'static encode': JSON.
- visuoattrsdata 'encode/decode roundtrip'.
- visuoattrsstyle 'url with colon': 'http://' не ломает парсер.
- visuoattrsstyle 'custom separators': '|' и '='.
- visuoattrsstyle 'skip empty': ';;' пропускается.
- visuoel: иерархия классов, css_class, data()->node === root.
- visuoel 'esc() escapes': <script> в &lt;script&gt;.
- visuoel_button: factory->submit/reset/button, multi, name/value/css_class, XSS экранируется.
- visuoel_form: form singleton, data()->set(name, method, action, title_text, form_jquery), file→POST+multipart.
- visuoel_field_wrap: text/password/email/file/textarea/select/checkbox/radio/checkbox_group/radio_group, hide_label, hide_hint, XSS в label/hint/error.
- visuoel_fieldset: legend пустой — не рисуется, XSS в legend экранируется.
- visuoel_input: input->text/password/hidden/submit, data->set(name,value,placeholder), required/readonly/disabled, XSS в placeholder.
- visuoel_table: дивный режим (div.visuotable, cols_N, colelsinline), html_mode (table, attr, rowspan, colspan), head/body/foot, XSS в cell->set, cell->html — сырой HTML.
- visuolink: favicon/css/js factory и as_tag, rand=true, rand с query, rand + якорь, resolve_rand.
- visuolog: rows_count, add, as_tag empty, release содержит 'Лог пустой', row hrtime/DateTime, final(false) печатает.
- visuometa: title/link factory, multiple links, title+links, clear, as_tag idempotent, visuotag_set.
- visuorelease: конструктор без main, init tree, settings/meta/visuotag accessor, visuotag_set/clear, final (doctype/html/head/body), final_ajax (data-ajax, ajax-init), meta+title, release_min/release_struct null no crash, settings из cookie, custom settings injection.
- visuostruct: construct, min/ajax/html factory, current priority min>ajax>html, html return_type, set(null) не перезаписывает, off(), off неизвестного — no-op.
- visuostruct_ajax: address/header/top/left/right/center/bottom, as_json, error=true, JSON_UNESCAPED_UNICODE, json structure (error/address/layers), 6 layers.
- visuostruct_min: error/messages/release/form/referer, set/reset/redirect, referer falsy '0', referer null → server fallback, JSON-структура.
- visuotag: empty root, tag/content/release tree, self-closing, nested, parent navigation, parent('div', eq), append/prepend/clear, attrs_add, attrs_class_add, data_add, id, next, tag with named params, final, find(eq), find(by class/id), _body/_html missing, attrs/style/actions/data add/remove, full combination, release mixed/deep/attrs, prepare, releasetree, tree(), release empty content, structv, el, meta append, findstruct.

5. Скрытая логика
Тесты visuo не используют DB и filesystem — изолированы от окружения. В visuoattrs проверяется порядок атрибутов при release (class → style → actions → id). В visuotag find поддерживает eq как позиционный индекс совпадения. structv создаёт тег 'struct' с классом cl_struct (без id) — это специальный структурный контейнер. data-атрибуты кодируются через visuoattrsdata::encode: строки без json → простое значение, bool/int/array — JSON. XSS-проверки проверяют отсутствие literal '<script>' и наличие '&lt;script&gt;'.
