1. Назначение
Система атрибутов visuotag. visuoattrs — контейнер generic-атрибутов и владелец четырёх подконтейнеров: visuoattrsclass (множество class-имён), visuoattrsstyle (css-свойства), visuoattrsactions (on*-события), visuoattrsdata (data-* через JSON или как строку). release() собирает все атрибуты в строку в порядке class → style → actions → generic → data. attributes_release() возвращает только generic. whitelist для actions: /^on[a-z]+$/.

2. Контракт (Методы)
visuoattrs: __construct(?visuotag), visuotag(): ?visuotag, add(string, string, bool=false): visuoattrs, remove(string), get(string): mixed, has(string): bool, all(): array, clear(): visuoattrs, class(): visuoattrsclass, style(): visuoattrsstyle, actions(): visuoattrsactions, data(): visuoattrsdata, class_add/remove, style_add/remove, actions_add/remove, data_add(string, mixed, bool=true), data_remove, release(): string, attributes_release(): string
visuoattrsclass: __construct(visuoattrs), parent(): ?visuotag, add(string), remove(string), clear(), has(string): bool, get(string): string, all(): array, release(bool=true): string, private split(string)
visuoattrsstyle: __construct(visuoattrs), parent(), add(string, pair_separator=';', kv_separator=':'), remove(string), clear(), has(string), get(string), all(), release(bool=true), private split
visuoattrsactions: __construct(visuoattrs), parent(), tag(), add(string, string), remove(string), clear(), has(string), get(string), all(), shorthand onclick/ondblclick/onmousedown/onmouseup/onmouseover/onmouseout/onmousemove, release(bool=true), private is_event(string)
visuoattrsdata: __construct(?visuoattrs), add(string, mixed, bool=true), get(string): mixed, has(string): bool, remove(string), clear(), all(): array, owner(): ?visuoattrs, static encode(mixed): string, static decode(string): mixed, release(): string

3. Зависимости
visuotag (обратная ссылка), htmlspecialchars, json_encode/decode, preg_match, preg_split, random.

4. Edge-cases
- visuoattrs::add: value==='' и add_empty=false — атрибут не добавляется.
- visuoattrs::add: value==='' и add_empty=true — атрибут с пустым значением.
- visuoattrs::get: несуществующий ключ — null (array_key_exists проверка, не isset).
- visuoattrs::clear: очищает generic и все четыре подконтейнера.
- visuoattrs::release: порядок class, style, actions, attributes, data — фиксирован.
- attributes_release: elements пуст — ''.
- visuoattrsclass::add: split по \s+, пустые — [];
- visuoattrsclass::remove: удаление по каждому split-элементу.
- visuoattrsclass::has: isset, не array_key_exists — удалённые ключи не считаются.
- visuoattrsclass::release: full=false — без ' class="..."'.
- visuoattrsstyle::add: pair без ':' — пропуск; пустой pair — пропуск; пустое имя — пропуск.
- visuoattrsstyle::add: значение после ':' обрезается trim; внутренние ':' сохраняются (url(http://...)).
- visuoattrsstyle::release: сборка 'name:value;' в порядке добавления, затем htmlspecialchars.
- visuoattrsstyle::remove: split по \s+ — можно удалять несколько имён.
- visuoattrsactions::add: action не matches /^on[a-z]+$/ — return без изменений; value==='' — return.
- visuoattrsactions::add: action нормализуется strtolower(trim).
- visuoattrsactions::has/get/remove: тоже strtolower(trim).
- visuoattrsactions::release: full=false — trim от html; при пустом elements '' независимо от full.
- visuoattrsactions::release: значения htmlspecialchars.
- visuoattrsdata::add: value любой из null|bool|string|int|array; to_json=true — сериализуется JSON_UNESCAPED_UNICODE; false — (string).
- visuoattrsdata::encode: json_encode false — ''.
- visuoattrsdata::release: key всегда с префиксом 'data-'; значение htmlspecialchars.
- visuoattrsdata::get: array_key_exists — null-значение возвращается, а не пустая строка.
- visuoattrsdata::release: порядок = порядок добавления.

5. Скрытая логика
visuoattrs держит generic-атрибуты в elements и четыре подкласса в отдельных свойствах. release() фиксирует порядок сериализации: сначала class, затем style, затем actions, затем generic (id, name, href), затем data. Это соответствует тестам в старом проекте. Все подклассы делят visuotag через visuoattrs->visuotag(), чтобы parent() возвращал исходный узел. Дочерние контейнеры при clear() очищаются visuoattrs::clear(). is_event — единственная защита от инъекции не-on* атрибутов через actions_add (тест 'non-event rejected' ожидает, что href не попадёт). visuoattrsdata::encode по умолчанию json_encode, поэтому строка "admin" превращается в '"admin"', а int 5 — в '5', bool — 'true'/'false'; тест 'add string no json' обходит это через to_json=false.
