1. Назначение
Накопитель логов в памяти в рамках запроса. log хранит массив log_row, поддерживает добавление, чтение, сброс, рендер в visuotag. log_row — одна запись (message, method, file, line).

2. Контракт (Методы)
log::__construct(main), add(string, string method='', string file='', int line=0): void, all(): array, count(): int, has(): bool, clear(): void, as_tag(): visuotag, astag(): visuotag
log_row::__construct(log, string, string, string, int), as_tag(): visuotag, astag(): visuotag

3. Зависимости
main, visuotag.

4. Edge-cases
- log::as_tag при пустом rows — возвращает пустой visuotag без элементов.
- log_row::as_tag всегда возвращает visuotag с div.log-row, вложенными div.log-line, div.log-message, div.log-source.
- log_row::as_tag в source конкатенирует method, file и line через пробел и двоеточие.
- astag — алиас as_tag.

5. Скрытая логика
log не пишет в файл, хранит записи только в памяти. log_row::as_tag строит цепочку tag(...)->parent() где parent возвращает на уровень выше. Цепочка заканчивается на div.log-source, поэтому log-message и log-line оказываются вложенными в log-row.
