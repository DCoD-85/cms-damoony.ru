1. Назначение
Контроллер медиа админки. list — обзор каталога www/media, построение списка папок и файлов, защита от Path Traversal через realpath. upload — приём файла, MediaUpload, редирект с параметром saved/error. delete — удаление одного файла, запрет удаления папок.

2. Контракт (Методы)
MediaController: list(), upload(), delete()

3. Зависимости
Paths::mediaRoot, Paths::real, Config, Fs::mkdir, CS_CMD/MediaUpload.php, AuditLog, $_FILES, $_GET, $_POST, scandir, filesize, filemtime, realpath, unlink.

4. Edge-cases
- list: path пуст и domain непуст — path = Paths::real(domain).
- list: domain пуст и path непуст — possible_domain = первые сегмент path; если domains_real[possible_domain] есть — domain = possible_domain.
- list: path содержит '..' или '\\' — redirect media:list.
- list: realpath(current) false или не начинается с realpath(root) — redirect media:list.
- list: '.' и '..' и скрытые файлы (name[0]=='.') пропускаются.
- list: dirs и files сортируются strcmp по name.
- upload: requirePost, target_path содержит '..' — redirect media:list.
- upload: Fs::mkdir(dir) до realpath-проверки — каталог может создаться, потом проверка.
- upload: realpath(dir) вне root — redirect media:list.
- upload: MediaUpload::run с dir и $_FILES['file'] или null.
- upload: AuditLog::action_ok('media:upload', path, file name, ok) даже при провале загрузки.
- upload: редирект с saved=1 при ok, иначе error=<errors[0]>.
- delete: requirePost, path с '..' — redirect.
- delete: realpath(full) false, вне root, или is_dir — redirect media:list.
- delete: unlink(real_full), AuditLog::action_ok.
- delete: parent = dirname(path); '.' — пустая строка.

5. Скрытая логика
list отклоняет '..' и '\\' строково, затем повторяет проверку через realpath-префикс. path в URL относительный, домен подтягивается из первого сегмента только если совпал с domains_real. upload делает mkdir до проверки realpath-префикса, поэтому Fs::mkdir может создать каталог вне mediaRoot при нештатном target_path, а проверка realpath сработает только после создания — фактическая запись не произойдёт, но пустой каталог останется. delete проверяет is_dir(real_full) — попытка удалить каталог не проходит. Все три метода пишут AuditLog, при upload — с исходным именем файла из $_FILES.
