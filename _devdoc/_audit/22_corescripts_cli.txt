1. Назначение
CLI-точка входа для corescripts. Разрешает запуск только в PHP_SAPI=cli. Определяет константы CS_ROOT, CS_LIB, CS_CMD, CS_TPL, PROJECT_ROOT. Подключает базовые _lib. Разбирает argv: команда, ключи --key=value, флаги --flag, позиционные, -h. Формирует params, вызывает Class::run(params, Context), печатает через Renderer::cli, exit(0) при ok, exit(1) иначе.

2. Контракт (Методы)
Верхнеуровневый скрипт. Классов не объявляет.

3. Зависимости
CS_LIB/Cli.php, Fs.php, Json.php, Paths.php, Blocks.php, Template.php, Config.php, Validate.php, Result.php, Context.php, Renderer.php, commands/*.php, $_SERVER['argv'].

4. Edge-cases
- PHP_SAPI !== 'cli' — die('Only CLI mode allowed').
- command не задан — $command='help'.
- command='help' или отсутствует в $map — Cli::help(merge(['help'],keys)), exit(0).
- команда в $map, но файла нет — Cli::err('Command not implemented'), exit(1).
- -h — печать Usage и exit(0).
- Class::run бросил Throwable — Cli::err(message), exit(2).
- class_exists($class) false — Cli::err('Class not found'), exit(1).
- positional не пуст и params['name'] не задан — params['name']=positional[0].
- positional не пуст — params['positional']=positional всегда.

5. Скрытая логика
Карта команд связывает имя команды, файл и класс: domain:new, domain:list, domain:remove, allias:new, allias:list, allias:remove, page:new, block:new, filler:new, admin:passwd, settings:set, settings:list, page:toggle, allias:toggle, domain:toggle, filler:toggle, filler:remove, block:remove, vars:extract. Context получает callback, который печатает Cli::ok/Cli::err в момент вызова $ctx->step из команды, то есть шаги выполняются последовательно во время run. Renderer::cli формирует финальный отчёт. Код возврата: 0 ok, 1 неуспех, 2 исключение.
