# AIUI (AI User Interface)

AIUI — это интерфейс для редактирования страниц с помощью естественного языка (промптов). Пользователь не пишет PHP-код и не редактирует JSON вручную, а общается с LLM (Qwen 2.5 Coder), которая перестраивает блоки страницы.

## 1. Архитектура

1. **Frontend (`www/admin/aiui.php`)**: Split-screen интерфейс. Слева — iframe с предпросмотром сайта, справа — чат.
2. **AJAX Endpoint (`www/admin/ai_edit.php`)**: Принимает POST-запрос с промптом.
3. **Backend (`php bin/cli.php ai:edit-page`)**: 
   - Читает текущий JSON блоков из `editor.json`.
   - Отправляет промпт и текущий JSON в `AgentChatHandler` (LLM).
   - Валидирует ответ LLM (извлекает JSON, убирает markdown-обертки).
   - Вызывает `page:write` для компиляции нового PHP-кода и сохранения `editor.json`.
4. **Компилятор (`PageCompiler` / `BlockCodegen`)**: Генерирует безопасный PHP-код из JSON.

## 2. Использование

### Через Web UI (для контент-менеджеров)
Открой в браузере:
`http://[domain]/admin/aiui.php?domain=[domain]&alias=[alias]&page=[page]`

В чате напиши задачу: *«Добавь H1 "Напишите нам" перед формой»*, *«Поменяй фон секции на темный»*. ИИ вернет новый JSON, `page:write` перекомпилирует страницу, и превью обновится.

### Через CLI (для разработчиков и скриптов)
```bash
php bin/cli.php ai:edit-page \
  --domain=example.ru \
  --alias=www \
  --page=contacts \
  --prompt="Добавь форму обратной связи" \
  --force=1
```
*Флаг `--force=1` обязателен для применения изменений. Без него — dry-run.*

## 3. Безопасность

- **Никакого raw PHP.** LLM отдает только JSON, `BlockCodegen` генерирует PHP безопасно через `Builder`.
- **Валидация JSON.** Если LLM вернул мусор, команда падает с ошибкой, страница не перезаписывается.
- **Роли.** Команда `ai:edit-page` доступна роли `designer` (и `*`).
- **Dry-run по умолчанию.** Без `--force=1` возвращает diff (старые/новые блоки), но не сохраняет.

## 4. Ограничения и P2

- **Нет diff-просмотра в Web UI.** Сейчас изменения применяются сразу. В Phase 3 добавим окно «Было / Стало» с кнопкой подтверждения.
- **LLM иногда обрезает JSON.** Частично решено в `brain.py` (через `_extract_json`), но в `ai:edit-page` пока простой парсинг.
- **Нет отката (Undo).** Если ИИ сломал разметку, придется откатывать через `git` (все изменения страниц коммитятся).
- **iframe на поддомене.** Для работы превью в локальной среде OSPanel должен резолвить поддомен `[alias].[domain]`.

## 5. Связанные команды
- `ai:edit-page` — редактирование страницы через LLM.
- `agent:chat` — низкоуровневое общение с LLM (используется внутри AIUI).
- `page:write` — сохранение JSON и компиляция.
