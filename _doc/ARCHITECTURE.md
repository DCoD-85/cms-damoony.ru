# Архитектура Damoony Engine

Движок построен по принципам Explicit over implicit и Contract-first. Ниже описано, как устроен жизненный цикл запроса и из каких слоев состоит система.

## 1. Точки входа

- `www/index.php` — Front Controller для публичного сайта.
- `www/admin/index.php` — Front Controller для админки.
- `bin/cli.php` — точка входа для консольных команд.

Все они инициализируют контейнер (PSR-11), окружение (Env) и ядро (Kernel).

## 2. Жизненный цикл HTTP-запроса

1. **Kernel**: принимает `Request`, оборачивает выполнение в `try/catch`, логирует ошибки и возвращает `Response`.
2. **Middleware**: `Kernel` пропускает запрос через стек middleware. Базовые: `SecurityHeadersMiddleware` (CSP, HSTS), `RateLimitMiddleware` (защита от брутфорса).
3. **FrontController**: 
   - Вызывает `DomainResolver::resolve($host)`, чтобы получить `DomainContext` (реальный домен, алиас, логика, доступность).
   - Проверяет доступность домена (если false, возвращает 503 Maintenance).
   - Вызывает `Router::match($path, $domain)`, чтобы найти маршрут.
4. **Router (FileRouter)**: идет по дереву папок `algoritm/` в `app/`, читает `.rules.json` на каждом шаге, сопоставляет сегменты URL и возвращает `RouteMatch` (имя класса, путь, аргументы).
5. **PageHandler**: если роут найден, подключает PHP-файл страницы, проверяет, что класс реализует `AlgoritmInterface`, инстанцирует его и вызывает метод `default()`.
6. **Algoritm (Страница)**: генерирует контент, возвращая объект `Node` (дерево UI) или `Response` (например, JSON или редирект).
7. **Response**: если возвращен `Node`, `PageHandler` оборачивает его в `Document` (тег `<html>`) и отдает HTML. Если возвращен `Response` — отдается как есть.

## 3. Слой домена (Domain)

Домен — это папка в `app/<logic>/domain/<real_domain>/`.
Внутри домена есть алиасы (`allias/www`, `allias/admin`). Каждый алиас содержит:
- `algoritm/` — дерево страниц (контроллеры).
- `alliasglobal/` — блоки (регионы шаблона).
- `alliasscheme/` — схемы (каркасы HTML).

`DomainResolver` позволяет одному реальному домену (`damoony.ru`) отвечать на несколько входящих хостов (`damoony.online`, `damoony3.ru`).

## 4. Слой UI

UI — это типизированное дерево, а не строки.
- `Node` — интерфейс любого узла.
- `Element` — HTML-тег (тег, атрибуты, дочерние элементы).
- `Attrs` — менеджер атрибутов, классов (`class="..."`), стилей и data-атрибутов с автоматическим экранированием (XSS-защита).
- `Builder` — статические методы-хелперы для быстрого создания типовых элементов (`Builder::div()`, `Builder::a()`).
- `Document` — корневой контейнер (`html`, `head`, `body`), который собирает итоговую страницу.

## 5. Регионы и Схемы

- **Region (Регион)**: интерфейс `RegionInterface`. Это независимый блок контента (например, шапка, футер, сайдбар). Он не знает о других регионах.
- **Scheme (Схема)**: `SchemeRenderer` берет декларативный манифест (массив `SchemeNode`), находит соответствующие регионы по их классам и собирает из них итоговый HTML-каркас страницы.
- **Filler**: механизм переопределения региона для конкретного алиаса (например, шапка для `admin` отличается от шапки для `www`).

## 6. Слой данных

Используется только PDO. Никаких ActiveRecord или QueryBuilder.
- `Connection` — ленивая инициализация PDO.
- `MigrationRunner` — последовательное применение `.sql` файлов из `migrations/` с фиксацией версий в таблице `migrations`.

## 7. CLI и Админка

- **CLI**: 13 команд, построенных на контракте `CommandInterface`. Каждая команда возвращает объект `Result` (успех/ошибка, шаги, созданные файлы). Используется для быстрого развертывания.
- **Admin**: базовая авторизация (`Auth`), защита от брутфорса, CSRF-токены. Админка выступает как тонкая обертка над CLI-командами и файловой системой.

## 8. Безопасность

- Входные данные в UI экранируются на уровне `Attrs::esc()` и `Text::escaped()`.
- Пароли хранятся только как хеши `password_hash` (bcrypt).
- Middleware автоматически выставляет заголовки безопасности (CSP, HSTS).
- CSRF-токены обязательны для всех POST-запросов в админке.
- Загрузка файлов (Media) ограничена белым списком расширений, запрещены `.php` и скрипты.
