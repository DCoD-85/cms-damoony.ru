# AI Wizard & Agent Factory (Web UI)

Документ описывает архитектуру веб-интерфейса для автономной генерации сайтов. 
Интерфейс позволяет пользователю общаться с LLM для сбора брифа, а затем асинхронно запускает `ai_agent/brain.py` в фоне, отслеживая прогресс без перезагрузки страницы.

---

## 1. Карта процессов (Data Flow)

1. **Интервьюер (Frontend):** Пользователь общается с LLM через чат. История диалога хранится в JS-массиве `chatHistory` в оперативной памяти браузера.
2. **Триггер (AJAX):** При вводе команды «Создавай» JS отправляет `history` на `algoritm_ajax.php` (`action=generate`).
3. **Background Job (PHP -> Python):** PHP собирает бриф в `var/*_brief.txt`, создает `.bat` скрипт и запускает `brain.py` в фоне (через `cmd /c start /B`). AJAX мгновенно возвращает `session_id`.
4. **Multi-Agent (Python):** `brain.py` работает независимо от веб-сервера. Он вызывает `bin/aicli.php` (через `wizard:*`) для безопасной сборки сайта.
5. **Status Polling:** JS каждые 3 секунды опрашивает `algoritm_ajax.php` (`action=status`). PHP читает лог-файл Python (`var/*_brain.log`), парсит текущую стадию (Architect, Content, CSS) и возвращает её фронтенду.
6. **Cancel:** Кнопка «Остановить» создает файл `var/{session_id}.cancel`. `brain.py` проверяет его наличие между задачами и корректно прерывает работу.
7. **Finish:** При появлении в логе `Done!` JS выводит пользователю кнопку со ссылкой на сгенерированный сайт.

---

## 2. Особенности реализации под Windows (OSPanel)

Так как веб-сервер (Apache) и CLI-утилиты работают в разных средах, применены архитектурные решения:

1. **Изоляция путей:** В `algoritm_ajax.php` жестко прописаны абсолютные пути к `php.exe` и `python.exe`. Apache не наследует системный `PATH` (в частности, не видит MSYS2 Python).
2. **Асинхронность:** Запуск Python происходит через генерацию временного `.bat` файла в `var/` и вызов `cmd /c start /B`. Это не блокирует поток PHP и не вешает Apache.
3. **Отслеживание статуса:** Статус определяется парсингом лога `brain.py` на наличие ключевых слов (`[1/5]`, `-> Writing`, `Done!`).

---

## 3. UI/UX (Frontend)

Интерфейс чата реализован на нативном JavaScript (fetch API) без jQuery.
- **Таймер:** Засекает время с момента запуска генерации.
- **Сброс контекста:** Если пользователь пишет «Удали» или «Сброс», JS очищает массив `chatHistory` и просит LLM начать интервью заново.
