Руководство пользователя админки
Панель управления доступна по адресу http://<ваш-домен>/admin/.

1. Вход в систему
При переходе по адресу админки откроется форма входа.

Введите логин и пароль, заданные при установке (по умолчанию admin / secret).

В целях безопасности после 5 неудачных попыток ввода пароля ваш IP-адрес блокируется на 15 минут.

2. Концепция: Домен и Алиас
Архитектура разделена на два логических уровня:

Домен (Инфраструктура): Управляет привязками входящих хостов, глобальными настройками (заглушки, статус) и глобальными блоками/схемами.

Алиас (Контент): Логические разделы сайта (www, doc, admin). У каждого алиаса свои страницы, переопределения блоков (fillers) и свои локальные схемы.

3. Уровень Домена
Главная страница «Домены» показывает список всех реальных доменов. Нажмите на название домена, чтобы открыть его панель управления.

Внутри домена доступны следующие вкладки:

3.1. Настройки
Заголовок (title): Название сайта.

Статус сайта: Глобальный переключатель вкл/выкл. Если выключить, все алиасы этого домена начнут отдавать 503 (Заглушку).

Заглушка: Выбор шаблона для выключенного сайта (например, «Реконструкция»).

Время авто-включения: Опциональная дата и время, когда сайт включится автоматически.

Удаление домена: Находится внизу страницы (в зоне опасности) и удаляет все файлы домена.

3.2. Привязанные домены
Управление входящими хостами (например, damoony.online, damoony.shop), которые ведут на этот реальный домен.

Список: Отображает входящие домены.

Сделать главным: Вырезает домен и ставит его первым в списке (главный домен используется для генерации абсолютных ссылок в шаблонах).

Отвязать: Позволяет удалить домен из списка или переназначить его на другой реальный домен.

Комментарий: Поле для заметки к каждому входящему домену.

Привязать домен: Добавление нового входящего домена (можно ввести новый или перенести из другого).

3.3. Алиасы
Список логических разделов (например, www для сайта, doc для документации).

Статус: Переключатель вкл/выкл. Выключение алиаса отдает 503 только для него, не затрагивая другие.

Имя: Клик по имени открывает дашборд алиаса.

Удалить: Безвозвратно удаляет папку алиаса и очищает конфиг.

3.4. Блоки (Глобальные)
Шаблонные элементы домена (шапка top, подвал bottom и др.). Хранятся в скрытой папке .alliasglobal/.

Создать блок: Создает базовые PHP-файлы.

Редактировать: Открывает встроенный редактор кода (с темной темой).

Удалить: Удаляет папку блока.

3.5. Схемы (Глобальные)
Глобальные HTML-каркасы домена. Хранятся в скрытой папке .alliasscheme/.

Создать схему: Создает файл .data.php (например, www.data.php).

Редактировать: Открывает редактор кода для настройки слотов и структуры.

3.6. БД домена
Раздел для управления подключением к базе данных и миграциями на уровне домена (заготовка для будущего).

4. Уровень Алиаса
Нажмите на имя конкретного алиаса (например, www), чтобы перейти в его дашборд.

4.1. Настройки алиаса
Управление параметрами конкретного алиаса (skin, title) — заготовка.

4.2. Страницы
Дерево страниц алиаса в папке algoritm/.

Создать страницу: Создает новую папку и PHP-файл контроллера.

Переход вглубь: Клик по странице открывает список её дочерних страниц.

Редактировать: Открывает редактор кода для изменения логики страницы.

4.3. Блоки (Fillers)
Переопределения глобальных блоков для текущего алиаса (например, top_www.php).

Создать filler: Создает файл переопределения.

Включить/Выключить: Если выключить, движок будет использовать глобальный блок.

Редактировать: Редактор кода для конкретного филлера.

4.4. Схемы алиаса
Локальные схемы для переопределения глобального каркаса (заготовка).

4.5. БД алиаса
Управление отдельной базой данных для алиаса (заготовка).

5. Медиа-менеджер
Раздел «Медиа» доступен на уровне домена.

Загрузка: Выберите файл и нажмите «Загрузить». Запрещена загрузка скриптов (.php).

Список: Показывает имя файла, размер и кнопку открытия.

Удаление: Защищено CSRF-токеном и подтверждением (через POST-форму).

6. Глобальные настройки
Раздел «Настройки» в верхней шапке админки.

Название сайта: Глобальный заголовок (fallback).

Язык по умолчанию: Основной язык системы.

7. Встроенный редактор кода
Любой файл (блок, схему, страницу) можно открыть в редакторе.

Интерфейс с темным фоном и моноширинным шрифтом.

Сохранение через кнопку «Сохранить» (защищено CSRF).

Возврат в предыдущий раздел осуществляется через кнопку «Назад» или хлебные крошки.
