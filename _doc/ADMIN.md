# Руководство пользователя админки

Панель управления доступна по адресу `http://<ваш-домен>/admin/`.

## 1. Вход в систему

При переходе по адресу админки откроется форма входа.
- Введите логин и пароль, заданные при установке (по умолчанию `admin` / `secret`).
- В целях безопасности после 5 неудачных попыток ввода пароля ваш IP-адрес блокируется на 15 минут.

## 2. Панель управления (Дашборд)

После успешного входа открывается главный экран. На нем отображается текущее количество доменов в системе и кнопка для перехода в раздел управления доменами.

## 3. Управление доменами

Перейдите по ссылке "Управление доменами". Вы увидите таблицу всех настроенных доменов, сгруппированных по реальному домену (со списком привязанных к нему входящих хостов).
- **Создать домен:** Нажмите "+ Добавить домен". Введите имя домена (например, `example.ru`) и, при необходимости, namespace (латиницей).
- **Действия с доменом:** В строке каждого домена доступны ссылки для перехода к управлению его компонентами:
  - **Алиасы:** Разделы сайта (например, `www` для основного сайта, `admin` для админки).
  - **Блоки:** Шаблонные элементы (шапка, подвал, меню).
  - **Страницы:** Дерево страниц конкретного алиаса.
  - **Схемы:** Каркасы HTML-страниц.
  - **Fillers:** Переопределения блоков для конкретного алиаса.
  - **Медиа:** Файловое хранилище для домена.
  - **Удалить:** Полное удаление домена со всеми файлами (безвозвратно).

## 4. Управление алиасами

Алиасы позволяют разделить сайт на логические части (например, основная версия и мобильная, или сайт и панель администратора).
- **Создать алиас:** Введите имя (латиницей) и нажмите "Создать".
- В списке отображаются все текущие алиасы домена. Рядом с каждым есть ссылка "Fillers" для управления его переопределениями.

## 5. Управление блоками (alliasglobal)

Блоки — это независимые куски контента (регионы), которые собираются в страницу через схемы.
- **Создать блок:** Введите имя блока (например, `top`, `bottom`, `policy`). Система создаст папку и базовые PHP-файлы для него.
- **Редактировать:** Нажмите ссылку "Редактировать", чтобы открыть встроенный редактор кода и изменить PHP-логику блока прямо в браузере.
- **Удалить блок:** Удаляет папку блока из файловой системы.

## 6. Управление страницами

Страницы отображаются в виде дерева.
- **Создать страницу:** Нажмите "+ Добавить страницу". Введите имя (латиницей, например `about` или `contacts`). Если вы находитесь внутри другой страницы, новая создастся как дочерняя.
- **Переход вглубь:** Клик по имени страницы открывает её внутреннее дерево (подстраницы).
- **Управление доступом:** С помощью кнопок "Auth On" / "Auth Off" можно включить или отключить требование авторизации для конкретной страницы (редактируется файл `.rules.json`).

## 7. Управление схемами (alliasscheme)

Схемы определяют, как блоки (регионы) собираются вместе в HTML-каркас страницы.
- **Создать схему:** Введите имя (например, `visuo`, `default`). Будет создан файл `.data.php`, в котором описано расположение блоков на странице.
- **Редактировать:** Нажмите ссылку "Редактировать", чтобы открыть встроенный редактор кода и изменить структуру и слоты схемы прямо в браузере.

## 8. Управление Fillers

Fillers (филлеры) позволяют изменить поведение блока для конкретного алиаса, не трогая остальные.
- **Создать filler:** Выберите блок из списка. Будет создан файл, переопределяющий логику этого блока для текущего алиаса.
- **Включение/Выключение:** В таблице Fillers можно быстро включить или выключить переопределение (это изменение записывается в `site.config`).

## 9. Медиа-файлы

Раздел "Медиа" работает как файловый менеджер.
- **Загрузка:** Выберите файл на компьютере и нажмите "Загрузить". Запрещена загрузка скриптов (.php).
- **Просмотр:** Отображается имя файла, его размер и ссылка для просмотра/скачивания.
- **Удаление:** Нажмите "Удалить" (с подтверждением), чтобы стереть файл с сервера.

## 10. Настройки сайта

Глобальные настройки движка:
- **Название сайта:** Заголовок, который может использоваться в шаблонах.
- **Язык по умолчанию:** Основной язык сайта (`ru-ru`, `en-en` и т.д.).
Нажмите "Сохранить", чтобы применить изменения. Они запишутся в конфигурационный файл `site.config`.
