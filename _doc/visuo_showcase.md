# Visuo Alias Showcase

`visuo` — это эталонный алиас, демонстрирующий архитектуру Damoony Engine. 
Общие принципы (роутинг, контракты, блоки) описаны в `_doc/arch.md` и `_doc/dev.md`.

## 1. Мультиязычность через регулярки
Вместо создания дублирующих папок под каждый язык, используется регулярное выражение в `algoritm.rules.json`.
Пример конфигурации:

    "available": {
        "": "^$",
        "lang": "^([a-z]{2})$"
    }

Язык передается в аргумент `$lang` и доступен в странице через `$this->args['lang']`.

## 2. БЭМ-сетка (dt_)
Все элементы имеют префикс `dt_` (Damoony Tag). 
- Сетка: `.dt`, `.dt_middle`, `.dt_main`, `.dt_sidebar`.
- Стили разделены по файлам в `www/media/damoony.ru/visuo/skin/default/css/`:
  `dt.css` (сетка), `main.css` (типографика), `components.css` (формы/кнопки), `mobile.css` (адаптив).

## 3. Схема и блоки
Схема `app/damoony.ru/.alliasscheme/visuo.php` использует атрибуты `data-block="top"` и т.д. 
`app.js` находит эти контейнеры и заменяет их содержимое при AJAX-навигации.

## 4. Авторизация
Защищенные страницы (например, `/ru/dashboard`) проверяют `$this->isAuthenticated()` внутри метода `content()`. При отсутствии сессии движок отдает 302 редирект.
