--- НАЧАЛО ДОКУМЕНТА ---

Руководство пользователя админки
Админка — это один из трех интерфейсов управления движком (остальные — CLI и AI-агент через `aicli.php`). 
Архитектурный принцип: Админка является «тонким клиентом». Она занимается только рендерингом HTML и валидацией форм. Все операции с файловой системой (создание, копирование, удаление) делегируются CLI-командам.

⚠️ Правило 3 файлов: Любая сущность в движке (Страница, Блок, Филлер, Схема) состоит из трех файлов: `{name}.php` (код), `{name}.rules.json` (настройки), `{name}.editor.json` (данные UI). Глобальные манифесты (`blocks.json`, `schemes.json`) удалены.

Панель управления
Доступна по адресу http://<ваш-домен>/admin/.

Вход в систему
При переходе открывается форма входа. Логин и пароль — из config/admin.config. По умолчанию: admin / secret (смените через php bin/cli.php admin:passwd).

После 5 неудачных попыток IP блокируется на 15 минут (var/admin_fails.json). Все попытки (успешные и неуспешные) пишутся в var/admin_logs.json. Разблокировка — в разделе «Безопасность».

Админка использует отдельную авторизацию, независимую от пользователей сайта (user:new создаёт пользователей для страниц с "auth": true, а не для админки).

Шапка, Языки, Профиль
В верхней части — тёмная навигационная панель. Справа — переключатель языков (RU / EN / ZH). Выбор сохраняется в cookie admin_lang. Список языков — из admin.config.

Аватарка → меню:
- «Мой профиль»: Сводка, Логирование (история входов), Безопасность (смена пароля).
- «Выйти».

Обзор системы (System Health)
Раздел «Обзор» показывает статус доменов и алиасов деревом.
- Зелёный (OK) — всё работает.
- Жёлтый (Внимание) — предупреждения (например, филлер включён, а слота в схеме нет).
- Красный (Ошибка) — критические проблемы (отсутствуют обязательные файлы из правила 3 файлов).

StructureChecker (источник данных «Обзора») проверяет наличие всех 3 файлов (`.php`, `.rules.json`, `.editor.json`) для каждого элемента, а также стыковку филлер↔слот.

Уровень Домена
Главная «Домены» — список реальных доменов. Нажмите на название → панель управления.

Вкладки:
- Настройки: Заголовок, Статус сайта (вкл/выкл 503), Выбор заглушки, Время авто-включения, Удаление домена.
- Привязанные домены: управление входящими хостами. ⚠️ Порт и trailing-dot нормализуются (можно использовать IP:порт).
- Алиасы: список разделов. Переключатель статуса и переход в дашборд алиаса.
- Блоки (Глобальные): шаблонные элементы домена (top, left, center и т.д.). 
  ✅ Визуальный редактор удален в целях безопасности (защита от RCE). 
  Редактирование происходит только через CodeMirror (кнопка «Код»). Настройки типа (script/visual/mixed) хранятся в `{name}.rules.json`.
- Схемы (Глобальные): HTML-каркасы. Создание, копирование, удаление.
  ✅ Визуальный редактор схем (Drag&Drop) сохранен. Работает на основе `{name}.editor.json`, сохраняет вложенность (visual может содержать другие блоки, script — конечный лист).
  ✅ Кнопка «Создать схему» вызывает команду `scheme:new`.
  ✅ Кнопки «Копировать» и «Удалить» вызывают команды `scheme:copy` и `scheme:remove`.
- БД домена: статус базы данных. (В разработке — заглушка.)
- Заглушки: HTML-файлы для 503. Создание, визуальное редактирование, удаление.

Уровень Алиаса
Нажмите на имя алиаса → дашборд.

Вкладки:
- Настройки: Заголовок, Статус алиаса, Заглушка, Активный скин, Разрешённые скины и языки.
- Блоки (Fillers): переопределения глобальных блоков. Кнопка «Синхронизировать» создаёт локальные файлы для всех глобальных блоков. Включить/Выключить: если выключено — используется глобальный блок. 
  ✅ Визуальный редактор удален. Редактирование только через CodeMirror.
- Страницы: Дерево страниц в algoritm/. Корень — `/` (algoritm.php). Вложенные страницы отображаются с отступом.
  ✅ У каждой страницы в дереве есть кнопка «Код» (CodeMirror), а также переключатели Auth (🔒) и Search (🔍) в виде цветных пилюль. Переключение происходит через POST+CSRF и записывается в `algoritm_{name}.rules.json`.
  ✅ Визуальный редактор страниц удален (в целях безопасности). Страницы пишутся только через код.
- Схемы алиаса: создание/удаление локальной схемы (переопределяет глобальную). Локальная схема хранится в `{name}.php` и `{name}.editor.json`.
- БД алиаса: статус подключения к MariaDB, количество таблиц, размер.

Глобальные разделы
- Заглушки: менеджер HTML-файлов для 503.
- Безопасность: количество ошибок входа за 24ч, список активных банов (Rate Limit) с кнопкой «Разблокировать».
- Настройки: глобальные параметры (название сайта, язык).

Встроенный редактор кода (CodeMirror)
Единственный инструмент для правки Страниц, Блоков и Филлеров. Открывается по кнопке «Код» или «Редактировать».
- Тёмная тема (Dracula).
- Нумерация строк.
- Подсветка PHP, HTML, CSS, JS.
- Автозакрытие скобок.
- Сохранение через «Сохранить» (POST + CSRF).

Визуальный редактор (Low-Code) — Только для Схем
Drag&Drop доступен только в разделе «Схемы». 
- Зоны: «Неактивные», «Скрипты» и «Визуал».
- Вы можете перетаскивать блоки в canvas, настраивать CSS-классы и вложенность.
- При сохранении JSON-структура из `{name}.editor.json` компилируется в чистый PHP (через SchemeCompiler).

Аварийный режим (Safe Mode)
Если конфигурация повреждена или в коде критическая ошибка — админка не отдаёт белый экран. Вместо этого — красная страница с текстом ошибки и кнопкой «Попробовать снова».
⚠️ Safe Mode работает на уровне www/admin/index.php (try/catch вокруг bootstrap).

Что НЕ работает в админке (ограничения)
- Создание пользователей сайта (user:new) — только CLI.
- Миграции БД (db:migrate) — только CLI.
- Очистка карантина (trash:clear) — только CLI.

Что делать при ошибках
Если вы видите ошибку структуры (желтый/красный статус) — запустите в терминале:
`php bin/cli.php structure:check` (диагностика) или `php bin/cli.php structure:repair --domain=example.ru` (автовосстановление .rules.json и .editor.json).
