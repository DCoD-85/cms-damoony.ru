Руководство пользователя админки

Панель управления доступна по адресу http://<ваш-домен>/admin/.

Вход в систему
При переходе по адресу админки откроется форма входа.
Введите логин и пароль. По умолчанию: admin / secret.
В целях безопасности после 5 неудачных попыток ввода пароля ваш IP-адрес блокируется на 15 минут. Все успешные и неудачные попытки входа записываются в журнал безопасности.

Шапка и переключатель языков
В верхней части экрана находится темная навигационная панель:

Слева: логотип проекта.

По центру: основные разделы (Домены, Заглушки, Безопасность, Настройки).

Справа: переключатель языков (RU / EN / ZH) и меню профиля.

Переключатель языков работает динамически. Доступные языки задаются в файле config/admin.config. Текущий активный язык выделен белым цветом. При клике на другой язык интерфейс мгновенно переводится, а выбор сохраняется в cookie.

Меню профиля
Справа в шапке находится круглая аватарка с буквой администратора.
При наведении открывается меню:

«Мой профиль» — переход в настройки учетной записи.

«Выйти» — завершение сессии.

Внутри «Моего профиля» доступны три вкладки:

Сводка: отображает текущий логин и роль.

Логирование: таблица последних 50 попыток входа (дата, IP, статус). Здесь же можно очистить лог, отправить его в архив или переключаться между страницами (пагинация).

Безопасность: форма смены пароля. Для изменения нужно ввести текущий пароль и дважды новый (при вводе нового пароля появляется цветовой индикатор его надежности).

Концепция: Домен и Алиас
Архитектура разделена на два логических уровня:

Домен (Инфраструктура): Управляет привязками входящих хостов, глобальными настройками, глобальными блоками и схемами.

Алиас (Контент): Логические разделы сайта (www, doc). У каждого алиаса свои страницы, переопределения блоков (fillers), локальные схемы и свой выбор языков/скинов.

Уровень Домена
Главная страница «Домены» показывает список всех реальных доменов. Нажмите на название домена, чтобы открыть его панель управления.
Внутри домена доступны следующие вкладки:

5.1. Настройки

Заголовок (title).

Статус сайта (вкл/выкл). При выключении все алиасы начинают отдавать 503 заглушку.

Выбор заглушки из списка.

Время авто-включения.

Удаление домена (зона опасности).

5.2. Привязанные домены
Управление входящими хостами (например, damoony.online), которые ведут на этот реальный домен.
Можно выбрать главный домен, отвязать домен, добавить комментарий или привязать новый хост.

5.3. Алиасы
Список логических разделов.

Статус (вкл/выкл для конкретного алиаса).

При клике на имя открывается дашборд алиаса.

5.4. Блоки (Глобальные)
Шаблонные элементы домена (top, left, center, right, bottom, policy). Хранятся в скрытой папке .alliasglobal/.

Создать блок: генерирует базовый PHP-класс (RegionInterface).

Редактировать: открывает встроенный редактор кода с подсветкой синтаксиса.

5.5. Схемы (Глобальные)
HTML-каркасы домена (хранятся в .alliasscheme/).

Создать схему.

Редактировать код схемы.

5.6. БД домена
Показывает статус базы данных домена (заготовка для будущего).

Уровень Алиаса
Нажмите на имя алиаса, чтобы перейти в его дашборд.

6.1. Настройки алиаса

Заголовок (title).

Статус алиаса (вкл/выкл).

Выбор заглушки и времени авто-включения.

Выбор активного скина (по умолчанию).

Разрешенные скины (чекбоксы).

Разрешенные языки (чекбоксы).

6.2. Блоки (Fillers)
Переопределения глобальных блоков для текущего алиаса.

Создать Filler (вручную).

Синхронизировать: автоматически находит все глобальные блоки домена и создает для них локальные файлы-переопределения, если их еще нет.

Включить/Выключить: если выключить, движок будет использовать глобальный блок.

Редактировать: открывает редактор кода.

6.3. Страницы
Дерево страниц алиаса в папке algoritm/.

Создать страницу: генерирует папку и PHP-класс.

Вход вглубь (вложенные страницы).

Кнопка «Наверх» для возврата к родительской папке.

Флаги Авторизация (auth) и Индексация (search): переключаются прямо в таблице. Безопасно (через POST).

Редактировать: открывает редактор кода.

6.4. Схемы алиаса
Позволяет создать локальную схему (скопирует глобальную и даст отредактировать только для этого алиаса).
Если локальной схемы нет, используется глобальная. Локальную схему можно удалить, чтобы вернуться к глобальной.

6.5. БД алиаса
Информационная панель. Показывает статус подключения к MariaDB, количество таблиц, размер базы. Есть кнопка «Проверить соединение».

Глобальные разделы (в шапке)
7.1. Заглушки (Stubs)
Менеджер HTML-заглушек для выключенных сайтов (503).

Создать заглушку (вводится имя, создается HTML-файл в папке stubs/).

Редактировать HTML-код (через редактор).

Удалить.

7.2. Безопасность
Дашборд безопасности.

Сводка: количество неудачных попыток входа за 24 часа.

Активные блокировки (Rate Limit): список IP-адресов, время до разблокировки и кнопка «Разблокировать».

Настройки лимитов: возможность менять max запросов, окно и время бана без правки конфигов.

7.3. Настройки
Глобальные настройки (название сайта, язык по умолчанию).

Встроенный редактор кода
Все файлы (блоки, схемы, страницы, заглушки) открываются в редакторе CodeMirror.

Темная тема (Dracula).

Нумерация строк.

Подсветка синтаксиса (PHP, HTML, CSS, JS).

Автозакрытие скобок.

Сохранение через кнопку «Сохранить» (защищено CSRF).

Аварийный режим (Safe Mode)
Если конфигурация (site.config, engine.config) повреждена или в коде возникла критическая ошибка, админка не выдает белый экран. Вместо этого она показывает красную страницу с текстом ошибки и кнопкой «Попробовать снова».
