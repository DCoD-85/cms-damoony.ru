Руководство пользователя админки

Панель управления доступна по адресу http://<ваш-домен>/admin/.

Вход в систему
При переходе по адресу админки откроется форма входа.
Введите логин и пароль, заданные при установке (по умолчанию admin / secret).
В целях безопасности после 5 неудачных попыток ввода пароля ваш IP-адрес блокируется на 15 минут. Все попытки входа логируются.

Шапка и переключатель языков
В верхней части экрана находится темная навигационная панель:

Слева: логотип проекта.

По центру (после входа): основные разделы (Домены, Заглушки, Безопасность, Настройки).

Справа: переключатель языков (RU / EN / ZH) и меню профиля.

Переключатель языков работает динамически. Доступные языки задаются в файле config/admin.config. Текущий активный язык выделен белым цветом. При клике на другой язык интерфейс мгновенно переводится, а выбор сохраняется в cookie (admin_lang).

Меню профиля
Справа в шапке находится круглая аватарка с первой буквой логина администратора.
При наведении на нее открывается выпадающее меню:

«Мой профиль» — переход в настройки учетной записи.

«Выйти» — завершение сессии.

Внутри «Моего профиля» доступны три вкладки:

Сводка: отображает текущий логин и роль (Суперадминистратор).

Логирование: таблица последних 50 попыток входа (успешных и неудачных) с указанием даты, времени, IP-адреса и статуса.

Безопасность: форма локальной смены пароля. Для изменения потребуется ввести текущий пароль и дважды новый (минимум 6 символов).

Концепция: Домен и Алиас
Архитектура разделена на два логических уровня:

Домен (Инфраструктура): Управляет привязками входящих хостов, глобальными настройками (заглушки, статус) и глобальными блоками/схемами.

Алиас (Контент): Логические разделы сайта (www, doc). У каждого алиаса свои страницы, переопределения блоков (fillers) и локальные схемы.

Уровень Домена
Главная страница «Домены» показывает список всех реальных доменов. Нажмите на название домена, чтобы открыть его панель управления.
Внутри домена доступны следующие вкладки:

5.1. Настройки

Заголовок (title): Название сайта.

Статус сайта: Глобальный переключатель вкл/выкл. Если выключить, все алиасы этого домена начнут отдавать 503 (Заглушку).

Заглушка: Выбор шаблона для выключенного сайта (например, «Реконструкция»).

Время авто-включения: Дата и время, когда сайт включится автоматически.

Удаление домена: Находится внизу (в зоне опасности) и удаляет все файлы домена.

5.2. Привязанные домены
Управление входящими хостами (например, damoony.online), которые ведут на этот реальный домен.

Список: Отображает входящие домены.

Сделать главным: Ставит домен первым в списке (используется для абсолютных ссылок).

Отвязать: Удалить домен из списка или переназначить.

Комментарий: Заметка к каждому домену.

Привязать домен: Добавление нового хоста (можно ввести новый или перенести из другого).

5.3. Алиасы
Список логических разделов (www, doc).

Статус: Выключение алиаса отдает 503 только для него.

Имя: Клик открывает дашборд алиаса.

Удалить: Перемещает папку алиаса в карантин.

5.4. Блоки (Глобальные)
Шаблонные элементы домена (шапка, подвал), хранящиеся в .alliasglobal/.

Создать блок: Создает базовые PHP-файлы (RegionInterface).

Редактировать: Открывает встроенный редактор кода.

5.5. Схемы (Глобальные)
HTML-каркасы домена, хранящиеся в .alliasscheme/.

Создать схему: Создает файл .data.php.

Редактировать: Открывает редактор кода для настройки слотов и структуры.

Уровень Алиаса
Нажмите на имя алиаса (например, www), чтобы перейти в его дашборд.

6.1. Страницы
Дерево страниц алиаса в папке algoritm/.

Создать страницу: Создает новую папку и PHP-файл контроллера.

Переход вглубь: Клик по странице открывает список её дочерних страниц.

Редактировать: Открывает редактор кода для изменения логики страницы.

6.2. Блоки (Fillers)
Переопределения глобальных блоков для текущего алиаса (например, top_www.php).

Создать filler: Создает файл переопределения.

Включить/Выключить: Если выключить, будет использоваться глобальный блок.

Редактировать: Редактор кода.

Медиа-менеджер
Раздел «Медиа» доступен на уровне домена.

Загрузка: Выберите файл и нажмите «Загрузить». Запрещена загрузка скриптов (.php).

Список: Показывает имя файла, размер и кнопку открытия.

Удаление: Защищено CSRF-токеном и подтверждением.

Глобальные настройки
Раздел «Настройки» в верхней шапке админки.

Название сайта: Глобальный заголовок.

Язык по умолчанию: Основной язык системы.

Встроенный редактор кода
Любой файл (блок, схему, страницу) можно открыть в редакторе.
Интерфейс с темным фоном и моноширинным шрифтом.
Сохранение через кнопку «Сохранить» (защищено CSRF).
