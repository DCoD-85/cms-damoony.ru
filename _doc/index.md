Документация Damoony Engine
Вся документация по проекту. Разделена по назначению: разработчики, администраторы, AI-агенты.

Статус проекта: ~95% production-ready. 0 P0-блокеров до деплоя (~0.5 дня). Полное состояние — MANIFEST.md.

⚠️ Порядок приоритета при расхождении: код в src/ → MANIFEST.md → остальные документы _doc/ → комментарии в коде. Если документ противоречит MANIFEST.md — доверяйте MANIFEST.md.

Канон
MANIFEST.md — главный документ. Возможности (✅/🟡/❌), известные дефекты (§6), баги P0/P1/P2 (§7), инварианты (§8), backlog (§10), видение (§12). Читать первым.

Общие сведения
readme.md — обзор проекта, стек, быстрый старт, честный статус, известные проблемы.

philosophy.md — 10 принципов архитектуры и степень их соблюдения (с расхождениями).

Архитектура и контракты
architecture.md — жизненный цикл HTTP-запроса, слои, Low-Code-компиляция, Safe Mode.

contracts.md — контракты (DomainResolver, Router, Region, UI, Scheme, Auth, I18n, Skins, компиляторы, диагностика) с ограничениями.

scenarios.md — ключевые Use Cases со статусом ✅/🟡/🔴 и покрытием тестами.

Установка и использование
install.md — развёртывание (MariaDB, конфиги, веб-сервер). ⚠️ Требует проверки при запуске — возможны расхождения.

cli.md — 17 CLI-команд, флаги, идемпотентность, чего нет в CLI.

admin.md — админка: вход, профиль, домены, алиасы, блоки, схемы, визуальные редакторы, «что НЕ работает».

guide.md — руководство разработчика: Вариант A (со схемой) и Вариант B (без), блоки, схемы, компиляторы, чек-лист перед деплоем.

Инструкции для AI-агентов
ai_system.md — AI-Архитектор: инфраструктура через CLI/JSON, «чего не делать», чек-лист.

ai_logic.md — AI-Разработчик: PHP-код страниц и блоков, ограничения Builder, XSS, null, addslashes, чек-лист.

Планы и Roadmap
i18n_skins_plan.md — статус I18n и скинов. ⚠️ Частично устарел; истина — MANIFEST.md §4.
