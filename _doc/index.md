Документация Damoony Engine

В этой директории собрана вся документация по проекту. Документы разделены по назначению для удобства разработчиков, администраторов и AI-агентов.

Общие сведения
readme.md — Главная страница проекта. Описание философии, стека и краткий старт.
philosophy.md — 10 ключевых принципов архитектуры, на которых построен движок.
contracts.md — Основные архитектурные контракты (интерфейсы), которые нельзя нарушать.
architecture.md — Описание жизненного цикла HTTP-запроса, слоёв и компонентов.
scenarios.md — Список ключевых сценариев использования (Use Cases).

Установка и использование
install.md — Инструкция по развёртыванию проекта (настройка MariaDB, конфиги, веб-сервер).
cli.md — Справочник по всем консольным командам управления.
admin.md — Руководство пользователя веб-интерфейса администратора (включая профиль и языки).

Разработка
guide.md — Практическое руководство для разработчика (создание страниц, блоков, логики).
i18n_skins_plan.md — Архитектура и статус внедрения мультиязычности и скинов.
audit-map-between-oldandnew.md — Сравнительная карта: старый аудит SimplCMS -> новый движок.
audit-map-oldpro.md — Историческая справка по старому аудиту (можно пропустить).
audit_2026-10-27.md — Аудит расхождений документации и кода (актуальный на текущий момент).

Инструкции для AI-агентов
ai_system.md — Инструкция для AI-Архитектора: управление инфраструктурой через CLI/JSON.
ai_logic.md — Инструкция для AI-Разработчика: написание PHP-кода для страниц и блоков.
start_new_agent.md — Операционный briefing (локальный/боевой сервер, пути, git-workflow).
